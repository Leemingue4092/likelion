# 전자기학 정리 — 제7장 · 제8장

수업 PDF(제7장 정자계, 제8장 전류에 의한 자계)를 **초보자 기준으로** 다시 정리한 학습 노트입니다.

## 공부 순서 (추천)

1. [00-한눈에보기.md](./00-한눈에보기.md) — 전체 지도와 전기↔자기 대응표
2. [01-제7장-정자계.md](./01-제7장-정자계.md) — 자석, 쿨롱, H·B·자속, 가우스
3. [02-제8장-전류에의한자계.md](./02-제8장-전류에의한자계.md) — 암페어, 솔레노이드, 비오-사바르, 전자력
4. [03-연습문제-해설.md](./03-연습문제-해설.md) — 개념·계산 문제 + 풀이

## 이 노트의 특징

- **비유 → 정의 → 공식 → 주의점** 순서로 적었습니다.
- 수업 필기에서 헷갈린 부분(왕복전류 합성자계, 원주도체 외부 \(H\) 그래프 등)을 따로 설명했습니다.
- 공식은 SI 단위 기준입니다. \(\mu_0 = 4\pi \times 10^{-7}\,\mathrm{H/m}\)

## 핵심 한 줄

| 장 | 한 줄 요약 |
|---|---|
| 7장 | 자석은 항상 N·S가 쌍으로 있고, \(B\)는 폐곡면으로 들어오고 나가는 양이 같아 \(\oint B\cdot dS=0\) |
| 8장 | 전류가 자계의 원천이고, 대칭이 좋으면 암페어 법칙 \(\oint H\cdot dl=I\)로 \(H\)를 구한다 |
