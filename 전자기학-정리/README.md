## 이 노트의 특징

- **왜? → 정의 → 공식 → 주의점** 순서로 적었습니다. 자기력선이 \(N=HS\cos\theta\), \(N=m/\mu_0\)인 이유와 \(H\)·\(B\) 관계도 풀어 썼습니다.
- 수업 필기에서 헷갈린 부분(왕복전류 합성자계, 원주도체 외부 H 그래프 등)을 따로 설명했습니다.
- 분수는 아래처럼 **위에 분자 / 가운데 선 / 아래 분모** 형태로 적습니다.

```
       4π μ₀ r²
```

## 핵심 한 줄

| 장 | 한 줄 요약 |
|---|---|
| 7장 | 자석은 항상 N·S가 쌍으로 있고, ∮ B · dS = 0 (고립자극 없음) |
| 8장 | 전류가 자계의 원천이고, 대칭이 좋으면 ∮ H · dℓ = I 로 H를 구한다 |
