제7장 정자계

시간에 따라 변하지 않는 자계. 이 장에서는 주로 자석을 다룹니다.

7.1 자석

  • 자극: N(+)극 / S(−)극. 작용이 강한 양 끝
  • 자기력: 동종 반발, 이종 흡인
  • 자하 m: 단위 [Wb]. 항상 N·S가 쌍으로 존재
  • 자석을 잘라도 작은 자석 두 개가 됨 (고립자극 없음)

7.2 쿨롱의 법칙

F = m₁ m₂4π μ₀ r² [N]

μ₀ = 4π × 10⁻⁷ H/m. 전기 쿨롱에서 Q→m, ε₀→μ₀.

7.3 자계의 세기 H

H = m4π μ₀ r² [A/m]
F = mH[N]

7.4 자위

단위 자하를 무한대에서 그 점까지 가져오는 데 드는 일.

U = −∫_∞^P H · dℓ
U = m4π μ₀ r [A]

7.5 자기력선

  • N에서 나와 S로 들어감 (안에서는 S→N, 폐회로)
  • 서로 교차하지 않음
  • 빽빽하면 셈 / 성기면 약함
  • 접선 방향 = 그 점의 자계 방향
N = HS cosθ ,  N = mμ₀

7.6 자속과 자속밀도

φ = BS cosθ ,  B = φS [T]
B = μ₀ H

가우스 정리

∮_S B · dS = 0,  ∇ · B = 0

고립자극은 없다. 전기의 ∮ D · dS = Q 와 가장 다른 점.

대응 핵심

E = −∇V,  H = −∇U

  • F, H 공식을 분수로 쓸 수 있는가?
  • ∮ B · dS = 0 을 설명할 수 있는가?
