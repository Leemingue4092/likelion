# 제8장 전류에 의한 자계 — 초보자용 정리

7장이 “자석이 만드는 자계”였다면,  
8장은 **전류가 만드는 자계**와 **자계가 전류·전하에 가하는 힘**입니다.

---

## 8.1 전류의 자기작용

### 전류의 세 작용

1. **자기작용** — 주변에 자계 생성 (이 장의 주제)
2. **발열작용** — 줄의 법칙
3. **화학작용** — 전기분해, 도금

### 역사 한 줄

외르스테드(전류 옆 자침) → 암페어·패러데이 → 맥스웰(전기·자기 통일)

### 핵심 관찰

직선 도체에 전류가 흐르면 주변에 **동심원 자계**가 생깁니다.  
전류 방향을 바꾸면 자침(자계) 방향도 반전됩니다.

> **전류 = 자계를 만드는 원천**

---

## 8.2 암페어의 오른나사(오른손) 법칙

### 방향 결정법

**오른나사 법칙**

- 나사가 진행하는 방향 → 전류 \(I\)
- 나사가 도는 방향 → 자계 \(H\) (또는 \(B\))

**오른손 법칙**

- 엄지 → 전류 \(I\)
- 나머지 네 손가락이 감는 방향 → 자계

직선 도체: 주변에 **동심원** 자계.

### 지면 표시 (시험에 자주 나옴)

| 기호 | 의미 |
|---|---|
| \(\odot\) (점) | 지면에서 **나오는** 방향 (화살촉) |
| \(\otimes\) (가위표) | 지면으로 **들어가는** 방향 (화살 꼬리) |

### 원형전류 / 왕복전류

- **원형 전류(루프):** 오른나사로 중심을 관통하는 자계 방향 결정
- **왕복전류(평행·반대방향):**
  - 두 도선 **사이**: 자계가 **같은 방향 → 합성 커짐**
  - **바깥**: 자계가 **반대 → \(I\) 같으면 상쇄 \(H \approx 0\)**

---

## 8.3 암페어의 주회적분 법칙

### 말

> 임의의 폐곡선에 대해 자계 \(\mathbf{H}\)를 한 바퀴 선적분하면,  
> 그 폐곡선이 감싸는(관통하는) **알짜 전류**와 같다.

### 식

\[
\oint_{c} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = I
\]

코일이 \(N\)번 관통하면:

\[
\oint_{c} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = NI
\]

**기호형:** ∮_c **H** · d**ℓ** = I \quad (또는 \(NI\))

### 전류 부호

폐곡선 적분 방향으로 오른나사를 돌릴 때,

- 나사 진행 방향과 같은 전류 → \(+\)
- 반대 → \(-\)

예: 폐로 안에 \(I_1(\odot),\ I_2(\otimes),\ I_3(\odot)\)이면  
알짜 전류 \(= I_1 - I_2 + I_3\).

---

## 8.4 전류에 의한 자계 계산

### 어떤 법칙을 쓸까?

| 상황 | 방법 |
|---|---|
| 무한장 직선, 원주도체, 무한장·환상 솔레노이드 (대칭 좋음) | **암페어 법칙** |
| 유한장 직선, 대칭 나쁨 | **비오–사바르** |
| 원형 도체 | 등가 판자석 / 비오–사바르 |

암페어를 쓸 때 적분로 고르는 요령:

1. \(\mathbf{H}\)와 \(\mathrm{d}\boldsymbol{\ell}\)이 **나란한** 원(또는 직선) → \(\mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = H\,\mathrm{d}\ell\)
2. \(\mathbf{H}\)와 \(\mathrm{d}\boldsymbol{\ell}\)이 **수직**인 구간 → 기여 0

---

### (1) 무한장 직선 전류

적분로: 반지름 \(r\)인 원.

\[
\oint H\,\mathrm{d}\ell = 2\pi r\, H = I
\quad\Rightarrow\quad
H = \frac{I}{2\pi r}\quad [\mathrm{A/m}]
\]

**기호형:** \(H = I / (2\pi r)\)

- \(H \propto 1/r\) (멀수록 약해짐)
- **투자율 \(\mu\)와 무관** (\(H\)만 구할 때)

진공: \(B = \mu_0 H = \dfrac{\mu_0 I}{2\pi r}\)

---

### (2) 무한장 원주형 도체 (반지름 \(a\), 전류 균일)

| 위치 | \(H\) | 기호형 |
|---|---|---|
| 외부 \(r > a\) | \(H = \dfrac{I}{2\pi r}\) | \(H = I/(2\pi r)\) |
| 표면 \(r = a\) | \(H = \dfrac{I}{2\pi a}\) | \(H = I/(2\pi a)\) |
| 내부 \(r < a\) | \(H = \dfrac{r I}{2\pi a^{2}}\) | \(H = rI/(2\pi a^{2})\) |

내부 유도 핵심:

- 적분로 안의 전류만 센다.
- 균일분포면 면적비: \(I' = I\cdot\dfrac{\pi r^{2}}{\pi a^{2}} = \dfrac{r^{2}}{a^{2}}I\)
- \(2\pi r\, H = I'\) → \(H = \dfrac{rI}{2\pi a^{2}}\)

**표면전류만** 흐르면:

- 내부 적분로가 감싸는 전류 \(= 0\) → **내부 \(H = 0\)**
- 외부는 그대로 \(H = I/(2\pi r)\)

분포:

```text
H
│     /\          ← 균일전류: 내부 ∝ r (직선), 외부 ∝ 1/r
│    /  \
│   /    ╲___
│  /
└───────────── r
   0    a

표면전류: 내부 0, r = a에서 점프 후 같은 1/r
```

---

### (3) 무한장 솔레노이드

솔레노이드 = 원통에 감은 코일.

- **내부:** 평등(균일) 자계  

\[
H_i = nI = \frac{NI}{l}\quad [\mathrm{A/m}]
\]

\(n = N/l\): 단위길이당 권수

**기호형:** \(H_i = nI = NI/\ell\)

- **외부:** 이상적인 경우 \(H = 0\)

---

### (4) 환상 솔레노이드 (토로이드)

도넛형 틀에 감은 코일. 자계는 **거의 내부에만**.

\[
\oint H\,\mathrm{d}\ell = 2\pi r\, H = NI
\quad\Rightarrow\quad
H = \frac{NI}{2\pi r} = \frac{NI}{l}
\]

\(\ell = 2\pi r\): 평균 자로 길이.

**기호형:** \(H = NI/(2\pi r) = NI/\ell\)

| 양 | 공심 | 철심 |
|---|---|---|
| \(H\) | \(\dfrac{NI}{2\pi r}\) (**동일**) | 같음 |
| \(B\) | \(\mu_0 H\) | \(\mu H\) |
| \(\phi = BS\) | \(\mu_0 H S\) | \(\mu H S\) |

> \(H\)는 전류·권수·기하만, \(B\)와 \(\phi\)는 매질(\(\mu\))에 따라 변함.

---

### 자계 세기 공식 정리

| 구분 | \(H\) [A/m] | 기호형 |
|---|---|---|
| 무한장 직선 | \(I/(2\pi r)\) | \(H = I/(2\pi r)\) |
| 무한장 솔레노이드 | \(nI = NI/l\) | \(H = nI\) (외부 0) |
| 환상 솔레노이드 | \(NI/(2\pi r) = NI/l\) | \(H = NI/(2\pi r)\) |
| 원형 코일 중심 | \(NI/(2a)\) | \(N=1\)이면 \(H = I/(2a)\) |

---

## 8.5 비오–사바르 법칙

대칭이 나쁠 때(유한 직선 등) 쓰는 **기본 법칙**.

\[
\mathrm{d}H = \frac{I\,\mathrm{d}\ell\sin\theta}{4\pi r^{2}}
\]

벡터형:

\[
\mathrm{d}\mathbf{H}
= \frac{I\,\mathrm{d}\boldsymbol{\ell}\times\hat{\mathbf{r}}}{4\pi r^{2}}
= \frac{I\,\mathrm{d}\boldsymbol{\ell}\times\mathbf{r}}{4\pi r^{3}}
\]

**기호형:**

- dH = I dℓ sinθ / (4π r²)
- d**H** = I (d**ℓ** × **r̂**) / (4π r²)

### 유한장 직선 전류

도선까지 수직거리 \(a\)인 점에서:

\[
H = \frac{I}{4\pi a}(\sin\phi_1 + \sin\phi_2)
= \frac{I}{4\pi a}(\cos\theta_1 + \cos\theta_2)
\quad [\mathrm{A/m}]
\]

**기호형:** \(H = \dfrac{I}{4\pi a}(\sin\phi_1 + \sin\phi_2)\)

무한장이면 \(\phi_1 = \phi_2 = 90^{\circ}\) → \(\sin = 1\)이 되어

\[
H = \frac{I}{2\pi a}
\]

로 암페어 결과와 같아집니다.

## 8.6 회전(∇×)과 스토크스 정리

### 보존장 vs 비보존장

| | 정전계 \(\mathbf{E}\) | 정자계 \(\mathbf{H}\) (전류 있을 때) |
|---|---|---|
| 폐경로 선적분 | \(\displaystyle\oint \mathbf{E}\cdot\mathrm{d}\boldsymbol{\ell} = 0\) | \(\displaystyle\oint \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = I\) |
| 회전 | \(\nabla\times\mathbf{E} = 0\) (보존장) | \(\nabla\times\mathbf{H} = \mathbf{J}\) (비보존장) |

**기호형:**

- ∮ **E** · d**ℓ** = 0 ,\quad ∇ × **E** = **0**
- ∮ **H** · d**ℓ** = I ,\quad ∇ × **H** = **J**

### 스토크스 정리

\[
\oint_{c} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell}
= \int_{S} (\nabla\times\mathbf{H})\cdot\mathrm{d}\mathbf{S}
\]

**기호형:** ∮_c **H** · d**ℓ** = ∬_S (∇ × **H**) · d**S**

암페어 법칙 **적분형 → 미분형**을 이끌어 내는 다리입니다.

## 8.7 자계 내 전류·전하가 받는 힘

### 전자력의 직관

평등자계 + 전류의 동심원 자계 = **합성 자력선이 한쪽으로 빽빽**.  
도체는 자속이 **성긴(감소하는) 쪽**으로 밀립니다.

### 전류가 받는 힘

\[
\mathbf{F} = I\,\boldsymbol{\ell}\times\mathbf{B},\qquad
F = BIl\sin\theta\quad [\mathrm{N}]
\]

**기호형:** **F** = I **ℓ** × **B** ,\quad F = BIl sinθ

방향: **플레밍 왼손법칙**

- 검지: \(B\) (자계)
- 중지: \(I\) (전류)
- 엄지: \(F\) (힘)

### 운동전하가 받는 힘

\[
\mathbf{F} = q(\mathbf{v}\times\mathbf{B}),\qquad
F = Bqv\sin\theta
\]

**기호형:** **F** = q (**v** × **B**) ,\quad F = Bqv sinθ

| 입사 | 운동 |
|---|---|
| \(B\)에 **수직** | **등속 원운동** |
| \(B\)에 **비스듬히** | **등속 나선운동** (\(v_{\parallel}\)는 그대로, \(v_{\perp}\)만 원운동) |

### 로렌츠 힘 (전계 + 자계)

\[
\mathbf{F} = q\bigl(\mathbf{E} + \mathbf{v}\times\mathbf{B}\bigr)
\]

**기호형:** **F** = q (**E** + **v** × **B**)

### 평행 도체 사이 힘

도선 A의 전류 \(I_1\)이 거리 \(d\)에 만드는 \(H = I_1/(2\pi d)\),  
\(B = \mu_0 H\)이면 길이 \(\ell\)인 도선 B(\(I_2\))가 받는 힘:

\[
F = \frac{\mu_0 I_1 I_2}{2\pi d}\,\ell
\]

**기호형:** \(F = \mu_0 I_1 I_2\,\ell / (2\pi d)\)

- 전류 **같은 방향** → 사이 자속 감소 → **흡인**
- 전류 **반대 방향** → 사이 자속 증가 → **반발**

## 8.9 핀치 · 홀 · 스트레치 효과

### 핀치 효과

액체 도체에 전류 → 전류 수직으로 원형 자계 → **구심 전자력으로 단면 수축**  
→ 저항 ↑ → 전류 ↓ → 수축 완화 → 다시 전류… 하는 현상.

### 홀 효과

도체/반도체에 전류 \(I\)와 직각으로 \(B\)를 걸면,  
\(I\)와 \(B\)가 이루는 면에 **직각 방향**으로 기전력(홀 전압) 발생.

### 스트레치 효과

가늘고 자유롭게 휘는 직사각 도선에 대전류 →  
반대 방향 전류끼리 반발 → 결국 **원형**에 가까워짐.
