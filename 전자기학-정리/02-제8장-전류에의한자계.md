# 제8장 전류에 의한 자계 — 초보자용 정리

7장이 “자석이 만드는 자계”였다면,
8장은 **전류가 만드는 자계**와 **자계가 전류·전하에 가하는 힘**입니다.

---

## 8.1 전류의 자기작용

### 전류의 세 작용

1. **자기작용** — 주변에 자계 생성 (이 장의 주제)
2. **발열작용** — 줄의 법칙
3. **화학작용** — 전기분해, 도금

### 역사 한 줄

외르스테드(전류 옆 자침) → 암페어·패러데이 → 맥스웰(전기·자기 통일)

### 핵심 관찰

직선 도체에 전류가 흐르면 주변에 **동심원 자계**가 생깁니다.
전류 방향을 바꾸면 자침(자계) 방향도 반전됩니다.

> **전류 = 자계를 만드는 원천**

---

## 8.2 암페어의 오른나사(오른손) 법칙

### 방향 결정법

**오른나사 법칙**

- 나사가 진행하는 방향 → 전류 I
- 나사가 도는 방향 → 자계 H (또는 B)

**오른손 법칙**

- 엄지 → 전류 I
- 나머지 네 손가락이 감는 방향 → 자계

직선 도체: 주변에 **동심원** 자계.

### 지면 표시 (시험에 자주 나옴)

| 기호 | 의미 |
|---|---|
| ⊙ (점) | 지면에서 **나오는** 방향 (화살촉) |
| ⊗ (가위표) | 지면으로 **들어가는** 방향 (화살 꼬리) |

### 원형전류 / 왕복전류

- **원형 전류(루프):** 오른나사로 중심을 관통하는 자계 방향 결정
- **왕복전류(평행·반대방향):**
  - 두 도선 **사이**: 자계가 **같은 방향 → 합성 커짐**
  - **바깥**: 자계가 **반대 → I 같으면 상쇄 H ≈ 0**

---

## 8.3 암페어의 주회적분 법칙

### 말

> 임의의 폐곡선에 대해 자계 H를 한 바퀴 선적분하면,
> 그 폐곡선이 감싸는(관통하는) **알짜 전류**와 같다.

### 식

```
∮_c H · dℓ = I
```

코일이 N번 관통하면:

```
∮_c H · dℓ = NI
```

### 전류 부호

폐곡선 적분 방향으로 오른나사를 돌릴 때,

- 나사 진행 방향과 같은 전류 → +
- 반대 → −

예: 폐로 안에 I₁(⊙), I₂(⊗), I₃(⊙)이면
알짜 전류 = I₁ − I₂ + I₃

---

## 8.4 전류에 의한 자계 계산

### 어떤 법칙을 쓸까?

| 상황 | 방법 |
|---|---|
| 무한장 직선, 원주도체, 무한장·환상 솔레노이드 (대칭 좋음) | **암페어 법칙** |
| 유한장 직선, 대칭 나쁨 | **비오–사바르** |
| 원형 도체 | 등가 판자석 / 비오–사바르 |

암페어를 쓸 때 적분로 고르는 요령:

1. H와 dℓ이 **나란한** 원(또는 직선) → H · dℓ = H dℓ
2. H와 dℓ이 **수직**인 구간 → 기여 0

---

### (1) 무한장 직선 전류

적분로: 반지름 r인 원.

```
∮ H dℓ = 2πr H = I
```

```
       I
H = ──────   [A/m]
      2π r
```

분모가 \(2\pi r\)인 이유: 적분로가 원이고 둘레가 \(2\pi r\)이라서 \(H\cdot 2\pi r=I\)입니다.
7장의 점자극은 구면(\(4\pi r^{2}\))으로 퍼져 \(1/r^{2}\)이고, 무한 직선은 원통처럼 퍼져 \(1/r\)입니다. 이차함수가 아닙니다.

- H ∝ 1/r (멀수록 약해짐)
- **투자율 μ와 무관** (H만 구할 때. 암페어 오른편이 전류이기 때문)

진공:

```
           μ₀ I
B = μ₀H = ──────
            2π r
```

---

### (2) 무한장 원주형 도체 (반지름 a, 전류 균일)

| 위치 | H (분수선) |
|---|---|
| 외부 r > a | H = I ⁄ (2πr) |
| 표면 r = a | H = I ⁄ (2πa) |
| 내부 r < a | H = rI ⁄ (2πa²) |

```
외부 / 표면                 내부 (균일전류)
       I                         r I
H = ──────                 H = ──────
      2π r                      2π a²
```

내부 유도 핵심:

- 적분로 안의 전류만 센다.
- 균일분포면 면적비:

```
         π r²       r²
I′ = I · ──── = I · ──
         π a²       a²
```

- 2πr H = I′ → H = rI ⁄ (2πa²)

**표면전류만** 흐르면:

- 내부 적분로가 감싸는 전류 = 0 → **내부 H = 0**
- 외부는 그대로 H = I ⁄ (2πr)

분포:

```text
H
│     /\          ← 균일전류: 내부 ∝ r (직선), 외부 ∝ 1/r
│    /  \
│   /    ╲___
│  /
└───────────── r
   0    a

표면전류: 내부 0, r = a에서 점프 후 같은 1/r
```

---

### (3) 무한장 솔레노이드

솔레노이드 = 원통에 감은 코일.

- **내부:** 평등(균일) 자계

```
         N I
Hᵢ = nI = ───   [A/m]
          ℓ
```

n = N ⁄ ℓ : 단위길이당 권수

- **외부:** 이상적인 경우 H = 0

---

### (4) 환상 솔레노이드 (토로이드)

도넛형 틀에 감은 코일. 자계는 **거의 내부에만**.

```
∮ H dℓ = 2πr H = NI
```

```
       N I         N I
H = ──────  =  ───
      2π r          ℓ
```

ℓ = 2πr : 평균 자로 길이

| 양 | 공심 | 철심 |
|---|---|---|
| H | NI ⁄ (2πr) (**동일**) | 같음 |
| B | μ₀H | μH |
| φ = BS | μ₀HS | μHS |

> H는 전류·권수·기하만, B와 φ는 매질(μ)에 따라 변함.
>
> 철심을 넣어도 암페어 오른편은 \(NI\)뿐이라 \(H\)는 그대로입니다. 철은 \(\mu\)가 커서 같은 \(H\)로도 \(B=\mu H\)가 커집니다.

---

### 자계 세기 공식 정리

| 구분 | H [A/m] | 비고 |
|---|---|---|
| 무한장 직선 | H = I ⁄ (2πr) | H ∝ 1/r |
| 무한장 솔레노이드 | H = nI = NI ⁄ ℓ | 외부 0 |
| 환상 솔레노이드 | H = NI ⁄ (2πr) = NI ⁄ ℓ | 외부 ≈ 0 |
| 원형 코일 중심 | H = NI ⁄ (2a) | N = 1이면 H = I ⁄ (2a) |

## 8.5 비오–사바르 법칙

대칭이 나쁠 때(유한 직선 등) 쓰는 **기본 법칙**.

```
          I dℓ sinθ
dH = ─────────────
           4π r²
```

벡터형:

```
          I (dℓ × r̂)           I (dℓ × r)
dH = ─────────────  =  ─────────────
           4π r²                  4π r³
```

### 유한장 직선 전류

도선까지 수직거리 a인 점에서:

```
       I
H = ────── (sinφ₁ + sinφ₂)   [A/m]
      4π a
```

```
       I
H = ────── (cosθ₁ + cosθ₂)   [A/m]
      4π a
```

무한장이면 φ₁ = φ₂ = 90° → sin = 1 이 되어

```
       I
H = ──────
      2π a
```

로 암페어 결과와 같아집니다.
\(4\pi\)가 \(2\pi\)로 바뀌는 것은 양쪽 끝 기여 \(\sin 90^{\circ}+\sin 90^{\circ}=1+1\) 때문입니다. 식이 달라 보여도 같은 물리량의 다른 계산법입니다.

## 8.6 회전(∇×)과 스토크스 정리

### 보존장 vs 비보존장

| | 정전계 E | 정자계 H (전류 있을 때) |
|---|---|---|
| 폐경로 선적분 | ∮ E · dℓ = 0 | ∮ H · dℓ = I |
| 회전 | ∇ × E = 0 (보존장) | ∇ × H = J (비보존장) |

### 스토크스 정리

```
∮_c H · dℓ = ∬_S (∇ × H) · dS
```

암페어 법칙 **적분형 → 미분형**을 이끌어 내는 다리입니다.

---

## 8.7 자계 내 전류·전하가 받는 힘

### 전자력의 직관

평등자계 + 전류의 동심원 자계 = **합성 자력선이 한쪽으로 빽빽**.
도체는 자속이 **성긴(감소하는) 쪽**으로 밀립니다.

### 전류가 받는 힘

```
F = I ℓ × B
```

```
F = BIl sinθ   [N]
```

방향: **플레밍 왼손법칙**

- 검지: B (자계)
- 중지: I (전류)
- 엄지: F (힘)

### 운동전하가 받는 힘

```
F = q (v × B)
```

```
F = Bqv sinθ
```

| 입사 | 운동 |
|---|---|
| B에 **수직** | **등속 원운동** |
| B에 **비스듬히** | **등속 나선운동** (v∥는 그대로, v⊥만 원운동) |

### 로렌츠 힘 (전계 + 자계)

```
F = q (E + v × B)
```

### 평행 도체 사이 힘

도선 A의 전류 I₁이 거리 d에 만드는

```
        I₁
H = ──────
      2π d
```

B = μ₀H 이면 길이 ℓ인 도선 B(I₂)가 받는 힘:

```
      μ₀ I₁ I₂ ℓ
F = ──────────
         2π d
```

- 전류 **같은 방향** → 사이 자속 감소 → **흡인**
- 전류 **반대 방향** → 사이 자속 증가 → **반발**

---

## 8.9 핀치 · 홀 · 스트레치 효과

### 핀치 효과

액체 도체에 전류 → 전류 수직으로 원형 자계 → **구심 전자력으로 단면 수축**
→ 저항 ↑ → 전류 ↓ → 수축 완화 → 다시 전류… 하는 현상.

### 홀 효과

도체/반도체에 전류 I와 직각으로 B를 걸면,
I와 B가 이루는 면에 **직각 방향**으로 기전력(홀 전압) 발생.

### 스트레치 효과

가늘고 자유롭게 휘는 직사각 도선에 대전류 →
반대 방향 전류끼리 반발 → 결국 **원형**에 가까워짐.
