상수: \(\mu_0 = 4\pi\times 10^{-7}\ \mathrm{H/m}\)

# A. 제7장 — 정자계

## 문제 A1. (개념) 자석을 잘랐을 때

막대자석을 정확히 가운데서 잘랐다. 생기는 조각은?

1. N극만 있는 조각과 S극만 있는 조각
2. 각각 N·S를 가진 작은 자석 두 개
3. 자극이 모두 사라진 철조각 두 개

### 해설

정답 **2**.  
자하는 홀로 존재할 수 없고, 잘라도 각 조각에 새 자극이 나타나 **작은 자석 두 개**가 됩니다.

---

## 문제 A2. (개념) 가우스 정리

폐곡면 \(S\)로 막대자석의 N극만 “대충” 감싸려고 했다.  
\(\displaystyle\oint_{S}\mathbf{B}\cdot\mathrm{d}\mathbf{S}\) 의 값은?

1. N극 세기 \(m\)에 비례하는 양수
2. 항상 0
3. 자석 길이에 비례

### 해설

정답 **2**.  
맥스웰 식

\[
\nabla\cdot\mathbf{B} = 0,\qquad
\oint_{S}\mathbf{B}\cdot\mathrm{d}\mathbf{S} = 0
\]

즉 **∇ · B = 0**, **∮ B · dS = 0** 은 언제나 성립합니다.  
전기의 ∮ **D** · d**S** = Q 와 가장 다른 점입니다.

## 문제 A3. (계산) 쿨롱 자기력

진공에서 두 점자극 \(m_1 = m_2 = 2\times 10^{-4}\ \mathrm{Wb}\)가  
\(r = 0.1\ \mathrm{m}\) 떨어져 있다. 서로 작용하는 힘의 크기를 구하시오. (동종극)

### 해설

\[
F = \frac{m_1 m_2}{4\pi\mu_0 r^{2}}
\]

**기호형:** \(F = m_1 m_2 / (4\pi\mu_0 r^{2})\)

\[
\begin{aligned}
F
&= \frac{(2\times 10^{-4})^{2}}{4\pi\mu_0\,(0.1)^{2}}
= \frac{4\times 10^{-8}}{4\pi\mu_0\times 10^{-2}}
= \frac{4\times 10^{-6}}{4\pi\mu_0}
= \frac{10^{-6}}{\pi\mu_0}
\end{aligned}
\]

\(\mu_0 = 4\pi\times 10^{-7}\) 대입:

\[
\pi\mu_0 = 4\pi^{2}\times 10^{-7}
\]

\[
F = \frac{10^{-6}}{4\pi^{2}\times 10^{-7}} = \frac{10}{4\pi^{2}} = \frac{2.5}{\pi^{2}} \approx 0.253\ \mathrm{N}
\]

동종극이므로 **반발력** 약 \(0.253\ \mathrm{N}\).

## 문제 A4. (계산) \(H\)와 \(F = mH\)

점자극 \(m = 4\pi\times 10^{-4}\ \mathrm{Wb}\)로부터 \(r = 0.2\ \mathrm{m}\)인 점에서 \(H\)를 구하고,  
같은 점의 시험자극 \(m' = 1\times 10^{-4}\ \mathrm{Wb}\)가 받는 힘을 구하시오.

### 해설

\[
H = \frac{m}{4\pi\mu_0 r^{2}}
= \frac{4\pi\times 10^{-4}}{4\pi\mu_0\,(0.2)^{2}}
= \frac{10^{-4}}{\mu_0\cdot 0.04}
= \frac{2.5\times 10^{-3}}{\mu_0}
\]

\[
H = \frac{2.5\times 10^{-3}}{4\pi\times 10^{-7}}
= \frac{2.5\times 10^{4}}{4\pi}
= \frac{6250}{\pi} \approx 1989\ \mathrm{A/m}
\]

\[
F = m'H = (1\times 10^{-4})\cdot\frac{6250}{\pi}
= \frac{0.625}{\pi} \approx 0.199\ \mathrm{N}
\]

## 문제 A5. (계산) 자속과 \(B = \mu_0 H\)

균일자계 \(H = 200\ \mathrm{A/m}\)인 진공 영역에서,  
면적 \(S = 0.05\ \mathrm{m^{2}}\)인 평면을 자계에 **수직**으로 놓았다.

1. 자속밀도 \(B\)
2. 면을 지나는 자속 \(\phi\)

### 해설

1. \(B = \mu_0 H = (4\pi\times 10^{-7})\cdot 200 = 8\pi\times 10^{-5} \approx 2.51\times 10^{-4}\ \mathrm{T}\)
2. \(\theta = 0^{\circ}\)이므로 \(\phi = BS = 8\pi\times 10^{-5}\cdot 0.05 = 4\pi\times 10^{-6} \approx 1.26\times 10^{-5}\ \mathrm{Wb}\)

## 문제 A6. (대응) 빈칸 채우기

정전계 \(E = \dfrac{Q}{4\pi\varepsilon_0 r^{2}}\)에 대응하는 정자계 식은?

### 해설

\(Q \rightarrow m\),\ \(\varepsilon_0 \rightarrow \mu_0\),\ \(E \rightarrow H\):

\[
H = \frac{m}{4\pi\mu_0 r^{2}}
\]

**기호형:** \(H = m / (4\pi\mu_0 r^{2})\)

# B. 제8장 — 전류에 의한 자계

## 문제 B1. (개념·방향) 오른손 법칙

지면에서 나오는 전류 \(\odot\)가 있을 때, 도선 **오른쪽** 점에서 \(H\)의 방향은?  
(위 / 아래 / 왼쪽 / 오른쪽 중)

### 해설

엄지를 나오는 방향(눈 쪽)으로 하면 손가락은 **반시계**로 감깁니다.  
도선 오른쪽에서는 손가락이 **위쪽**을 향합니다.  
정답: **위쪽**.

---

## 문제 B2. (개념) 왕복전류 합성

평행한 두 도선에 크기가 같은 전류가 **반대 방향**으로 흐른다.  
두 도선 **사이**와 **바깥**에서 합성 \(H\)의 특징은?

### 해설

- **사이:** 두 도선의 \(H\)가 같은 방향 → **보강(커짐)**
- **바깥:** 두 \(H\)가 반대 → **상쇄(이상적으로 ≈ 0)**

같은 방향 전류면 반대 패턴이고, 그때는 서로 **끌어당깁니다**.

---

## 문제 B3. (계산) 암페어 — 알짜 전류

폐곡선 \(c\)가 전류 \(I_1 = 3\ \mathrm{A}\ (\odot)\), \(I_2 = 5\ \mathrm{A}\ (\otimes)\), \(I_3 = 2\ \mathrm{A}\ (\odot)\)를 감싼다.  
적분 방향을 반시계로 잡을 때 \(\displaystyle\oint_{c}\mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell}\)의 값은?

### 해설

나오는 전류 \(+\),\ 들어가는 전류 \(-\):

\[
I_{\mathrm{encl}} = 3 - 5 + 2 = 0\ \mathrm{A}
\]

따라서

\[
\oint_{c}\mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = 0
\]

(**∮ H · dℓ = 0**)

## 문제 B4. (계산) 무한장 직선

무한장 직선에 \(I = 10\ \mathrm{A}\)가 흐른다. \(r = 0.05\ \mathrm{m}\)에서 \(H\)와 진공의 \(B\)를 구하시오.

### 해설

\[
H = \frac{I}{2\pi r} = \frac{10}{2\pi\cdot 0.05} = \frac{100}{\pi} \approx 31.8\ \mathrm{A/m}
\]

\[
B = \mu_0 H = 4\pi\times 10^{-7}\cdot\frac{100}{\pi} = 4\times 10^{-5}\ \mathrm{T}
\]

## 문제 B5. (계산) 원주도체 내부·외부

반지름 \(a = 2\ \mathrm{cm} = 0.02\ \mathrm{m}\)인 무한장 원주도체에 \(I = 20\ \mathrm{A}\)가 **균일**하게 흐른다.  
다음 위치의 \(H\)를 구하시오.

1. \(r = 1\ \mathrm{cm}\) (내부)
2. \(r = 2\ \mathrm{cm}\) (표면)
3. \(r = 4\ \mathrm{cm}\) (외부)

### 해설

1. 내부:  
   \(H = \dfrac{rI}{2\pi a^{2}} = \dfrac{0.01\cdot 20}{2\pi\cdot(0.02)^{2}} = \dfrac{250}{\pi} \approx 79.6\ \mathrm{A/m}\)

2. 표면:  
   \(H = \dfrac{I}{2\pi a} = \dfrac{20}{2\pi\cdot 0.02} = \dfrac{500}{\pi} \approx 159\ \mathrm{A/m}\)

3. 외부:  
   \(H = \dfrac{I}{2\pi r} = \dfrac{20}{2\pi\cdot 0.04} = \dfrac{250}{\pi} \approx 79.6\ \mathrm{A/m}\)

그래프는 내부에서 **∝ r** 로 올라갔다가 외부에서 **∝ 1/r** 로 내려갑니다.

## 문제 B6. (개념) 표면전류만 흐를 때

위 원주도체에서 전류가 **표면만** 흐른다면 \(r = 1\ \mathrm{cm}\)에서 \(H\)는?

### 해설

내부 적분로가 감싸는 전류 \(= 0\)이므로 \(H = 0\).

## 문제 B7. (계산) 무한장 솔레노이드

길이 \(\ell = 0.5\ \mathrm{m}\), 권수 \(N = 1000\), 전류 \(I = 2\ \mathrm{A}\)인 솔레노이드.

1. 내부 \(H\)
2. 외부 \(H\)
3. 진공일 때 내부 \(B\)

### 해설

1. \(H = \dfrac{NI}{\ell} = \dfrac{1000\cdot 2}{0.5} = 4000\ \mathrm{A/m}\)  
   (또는 \(n = N/\ell = 2000\ \mathrm{m^{-1}}\),\ \(H = nI = 4000\ \mathrm{A/m}\))
2. 이상적 무한장: **외부 \(H = 0\)**
3. \(B = \mu_0 H = 4\pi\times 10^{-7}\cdot 4000 = 1.6\pi\times 10^{-3} \approx 5.03\times 10^{-3}\ \mathrm{T}\)

## 문제 B8. (계산) 환상 솔레노이드 — \(H\)와 \(B\)

평균 반지름 \(r = 0.1\ \mathrm{m}\), \(N = 500\), \(I = 4\ \mathrm{A}\),  
단면적 \(S = 4\times 10^{-4}\ \mathrm{m^{2}}\).

1. 공심일 때 \(H\),\ \(B\),\ \(\phi\)
2. 투자율 \(\mu = 2000\mu_0\)인 철심일 때 \(H\),\ \(B\),\ \(\phi\)

### 해설

\(H\)는 매질 무관:

\[
H = \frac{NI}{2\pi r} = \frac{500\cdot 4}{2\pi\cdot 0.1} = \frac{10000}{\pi} \approx 3183\ \mathrm{A/m}
\]

**공심**

\[
B = \mu_0 H = 4\pi\times 10^{-7}\cdot\frac{10000}{\pi} = 4\times 10^{-3}\ \mathrm{T}
\]

\[
\phi = BS = 4\times 10^{-3}\cdot 4\times 10^{-4} = 1.6\times 10^{-6}\ \mathrm{Wb}
\]

**철심** (\(\mu = 2000\mu_0\))

\[
B = 2000\mu_0 H = 8\ \mathrm{T},\qquad
\phi = BS = 3.2\times 10^{-3}\ \mathrm{Wb}
\]

핵심: **\(H\)는 같고 \(B,\ \phi\)만 철심에서 커진다.**

## 문제 B9. (계산) 유한장 직선 (비오–사바르)

길이 \(L\)인 직선 도선 중심에서 수직거리 \(a\)인 점의 \(H\)를

\[
H = \frac{I}{4\pi a}(\sin\phi_1 + \sin\phi_2)
\]

로 구하려 한다. 도선 양 끝에서 그 점을 볼 때 \(\phi_1 = \phi_2 = \phi\)라면 \(H\)는?  
특별히 \(L \rightarrow \infty\)이면?

### 해설

대칭이므로

\[
H = \frac{I}{4\pi a}(2\sin\phi) = \frac{I\sin\phi}{2\pi a}
\]

기하: \(\sin\phi = \dfrac{L/2}{\sqrt{a^{2}+(L/2)^{2}}}\)

무한장: \(\phi \rightarrow 90^{\circ}\),\ \(\sin\phi \rightarrow 1\)

\[
H = \frac{I}{2\pi a}
\]

암페어 결과와 일치.

## 문제 B10. (계산) 전자력

\(B = 0.5\ \mathrm{T}\)인 평등자계에 길이 \(\ell = 0.2\ \mathrm{m}\) 도선이 자계와 \(30^{\circ}\)를 이루고  
\(I = 10\ \mathrm{A}\)가 흐른다. 도선이 받는 힘의 크기는?

### 해설

\[
F = BIl\sin\theta = 0.5\cdot 10\cdot 0.2\cdot\sin 30^{\circ} = 1\cdot 0.5 = 0.5\ \mathrm{N}
\]

**기호형:** \(F = BIl\sin\theta\)  
방향은 플레밍 왼손법칙(검지 \(B\), 중지 \(I\), 엄지 \(F\)).

## 문제 B11. (계산) 운동전하 · 원운동

\(B = 0.2\ \mathrm{T}\)에 수직으로 속력 \(v = 10^{6}\ \mathrm{m/s}\)인 전자  
(\(q = e = 1.6\times 10^{-19}\ \mathrm{C}\),\ 질량 \(m_e = 9.1\times 10^{-31}\ \mathrm{kg}\))가 들어간다.

1. 자기력의 크기
2. 원운동 반지름 \(r = \dfrac{mv}{qB}\)

### 해설

1. \(\theta = 90^{\circ}\)이므로  
   \(F = Bqv = 0.2\cdot 1.6\times 10^{-19}\cdot 10^{6} = 3.2\times 10^{-14}\ \mathrm{N}\)

2. 구심력 = 자기력: \(\dfrac{mv^{2}}{r} = Bqv\) → \(r = \dfrac{mv}{qB}\)

\[
r = \frac{9.1\times 10^{-31}\cdot 10^{6}}{1.6\times 10^{-19}\cdot 0.2}
= \frac{9.1\times 10^{-25}}{3.2\times 10^{-20}}
\approx 2.84\times 10^{-5}\ \mathrm{m}
\]

전자는 \(-\)전하라 힘 방향이 \(+\)전하와 반대임에 주의.

## 문제 B12. (계산) 평행도선 힘

두 무한장 평행도선이 \(d = 2\ \mathrm{cm}\) 떨어져 \(I_1 = I_2 = 30\ \mathrm{A}\)를 **같은 방향**으로 흘린다.  
길이 \(1\ \mathrm{m}\)당 힘의 크기와 흡인/반발 여부를 구하시오.

### 해설

\[
\frac{F}{\ell} = \frac{\mu_0 I_1 I_2}{2\pi d}
= \frac{4\pi\times 10^{-7}\cdot 30\cdot 30}{2\pi\cdot 0.02}
= 9\times 10^{-3}\ \mathrm{N/m}
\]

같은 방향 → **흡인력** \(9\ \mathrm{mN/m}\).

## 문제 B13. (개념) 홀 효과

반도체에 \(+x\) 방향으로 전류, \(+z\) 방향으로 \(B\)를 걸었다.  
홀 전압이 나타나는 대략적인 방향축은?

### 해설

\(I\)와 \(B\)에 **둘 다 수직**인 방향, 즉 \(y\)축 방향에 전하가 몰려 홀 전압이 생깁니다.  
(\(\mathbf{F} = q\,\mathbf{v}\times\mathbf{B}\) → **F** = q (**v** × **B**))
