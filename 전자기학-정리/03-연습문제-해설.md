푸는 요령: 먼저 **개념형**으로 감을 잡고, 그다음 **계산형**으로 공식을 손에 익히세요.

상수:

```
μ₀ = 4π × 10⁻⁷ H/m
```

# A. 제7장 — 정자계

## 문제 A1. (개념) 자석을 잘랐을 때

막대자석을 정확히 가운데서 잘랐다. 생기는 조각은?

1. N극만 있는 조각과 S극만 있는 조각
2. 각각 N·S를 가진 작은 자석 두 개
3. 자극이 모두 사라진 철조각 두 개

### 해설

정답 **2**.
자하는 홀로 존재할 수 없고, 잘라도 각 조각에 새 자극이 나타나 **작은 자석 두 개**가 됩니다.

---

## 문제 A2. (개념) 가우스 정리

폐곡면 S로 막대자석의 N극만 “대충” 감싸려고 했다.
∮_S B · dS 의 값은?

1. N극 세기 m에 비례하는 양수
2. 항상 0
3. 자석 길이에 비례

### 해설

정답 **2**.
맥스웰 식

```
∇ · B = 0
```

```
∮_S B · dS = 0
```

은 언제나 성립합니다.
전기의 ∮ D · dS = Q 와 가장 다른 점입니다.

## 문제 A3. (계산) 쿨롱 자기력

진공에서 두 점자극 m₁ = m₂ = 2×10⁻⁴ Wb가
r = 0.1 m 떨어져 있다. 서로 작용하는 힘의 크기를 구하시오. (동종극)

### 해설

```
        m₁ m₂
F = ────────────
       4π μ₀ r²
```

대입:

```
        (2×10⁻⁴)²
F = ─────────────────
     4π μ₀ · (0.1)²
```

```
      4×10⁻⁸           4×10⁻⁶           10⁻⁶
= ───────────── = ─────────── = ───────
   4π μ₀·10⁻²       4π μ₀          π μ₀
```

μ₀ = 4π×10⁻⁷ 대입:

```
π μ₀ = 4π² × 10⁻⁷
```

```
        10⁻⁶              10         2.5
F = ─────────────── = ─────── = ──── ≈ 0.253 N
     4π² × 10⁻⁷        4π²       π²
```

동종극이므로 **반발력** 약 0.253 N.

## 문제 A4. (계산) H와 F = mH

점자극 m = 4π×10⁻⁴ Wb로부터 r = 0.2 m인 점에서 H를 구하고,
같은 점의 시험자극 m′ = 1×10⁻⁴ Wb가 받는 힘을 구하시오.

### 해설

```
       m
H = ────────────
     4π μ₀ r²
```

```
      4π×10⁻⁴            10⁻⁴           2.5×10⁻³
= ──────────────── = ────────── = ─────────
   4π μ₀·(0.2)²       μ₀·0.04          μ₀
```

```
         2.5×10⁻³           2.5×10⁴        6250
H = ──────────────── = ────────── = ──── ≈ 1989 A/m
      4π×10⁻⁷               4π           π
```

```
                 6250         0.625
F = m′H = 10⁻⁴ · ──── = ───── ≈ 0.199 N
                  π            π
```

## 문제 A5. (계산) 자속과 B = μ₀H

균일자계 H = 200 A/m인 진공 영역에서,
면적 S = 0.05 m²인 평면을 자계에 **수직**으로 놓았다.

1. 자속밀도 B
2. 면을 지나는 자속 φ

### 해설

1. B = μ₀H = (4π×10⁻⁷)·200 = 8π×10⁻⁵ ≈ 2.51×10⁻⁴ T
2. θ = 0°이므로 φ = BS = 8π×10⁻⁵ · 0.05 = 4π×10⁻⁶ ≈ 1.26×10⁻⁵ Wb

# B. 제8장 — 전류에 의한 자계

## 문제 B1. (개념·방향) 오른손 법칙

지면에서 나오는 전류 ⊙가 있을 때, 도선 **오른쪽** 점에서 H의 방향은?
(위 / 아래 / 왼쪽 / 오른쪽 중)

### 해설

엄지를 나오는 방향(눈 쪽)으로 하면 손가락은 **반시계**로 감깁니다.
도선 오른쪽에서는 손가락이 **위쪽**을 향합니다.
정답: **위쪽**.

---

## 문제 B2. (개념) 왕복전류 합성

평행한 두 도선에 크기가 같은 전류가 **반대 방향**으로 흐른다.
두 도선 **사이**와 **바깥**에서 합성 H의 특징은?

### 해설

- **사이:** 두 도선의 H가 같은 방향 → **보강(커짐)**
- **바깥:** 두 H가 반대 → **상쇄(이상적으로 ≈ 0)**

같은 방향 전류면 반대 패턴이고, 그때는 서로 **끌어당깁니다**.

---

## 문제 B3. (계산) 암페어 — 알짜 전류

폐곡선 c가 전류 I₁ = 3 A (⊙), I₂ = 5 A (⊗), I₃ = 2 A (⊙)를 감싼다.
적분 방향을 반시계로 잡을 때 ∮_c H · dℓ 의 값은?

### 해설

나오는 전류 +, 들어가는 전류 − :

```
I_encl = 3 − 5 + 2 = 0 A
```

```
∮_c H · dℓ = 0
```

## 문제 B4. (계산) 무한장 직선

무한장 직선에 I = 10 A가 흐른다. r = 0.05 m에서 H와 진공의 B를 구하시오.

### 해설

```
       I             10           100
H = ────── = ───────────── = ──── ≈ 31.8 A/m
      2π r     2π·0.05         π
```

```
B = μ₀H = 4π×10⁻⁷ · (100 / π) = 4×10⁻⁵ T
```

## 문제 B5. (계산) 원주도체 내부·외부

반지름 a = 2 cm = 0.02 m인 무한장 원주도체에 I = 20 A가 **균일**하게 흐른다.
다음 위치의 H를 구하시오.

1. r = 1 cm (내부)
2. r = 2 cm (표면)
3. r = 4 cm (외부)

### 해설

1. 내부

```
       r I
H = ──────
      2π a²
```

```
      0.01·20              250
= ─────────────── = ──── ≈ 79.6 A/m
   2π·(0.02)²            π
```

2. 표면

```
       I              20           500
H = ────── = ──────────── = ──── ≈ 159 A/m
      2π a     2π·0.02         π
```

3. 외부

```
       I              20           250
H = ────── = ──────────── = ──── ≈ 79.6 A/m
      2π r     2π·0.04         π
```

그래프는 내부에서 **∝ r** 로 올라갔다가 외부에서 **∝ 1/r** 로 내려갑니다.

## 문제 B6. (개념) 표면전류만 흐를 때

위 원주도체에서 전류가 **표면만** 흐른다면 r = 1 cm에서 H는?

### 해설

내부 적분로가 감싸는 전류 = 0이므로 H = 0.

## 문제 B7. (계산) 무한장 솔레노이드

길이 ℓ = 0.5 m, 권수 N = 1000, 전류 I = 2 A인 솔레노이드.

1. 내부 H
2. 외부 H
3. 진공일 때 내부 B

### 해설

1.

```
       N I       1000·2
H = ───── = ─────── = 4000 A/m
        ℓ         0.5
```

(또는 n = N / ℓ = 2000 m⁻¹ , H = nI = 4000 A/m)

2. 이상적 무한장: **외부 H = 0**
3. B = μ₀H = 4π×10⁻⁷ · 4000 = 1.6π×10⁻³ ≈ 5.03×10⁻³ T

## 문제 B8. (계산) 환상 솔레노이드 — H와 B

평균 반지름 r = 0.1 m, N = 500, I = 4 A,
단면적 S = 4×10⁻⁴ m².

1. 공심일 때 H, B, φ
2. 투자율 μ = 2000μ₀인 철심일 때 H, B, φ

### 해설

H는 매질 무관:

```
       N I         500·4          10000
H = ────── = ──────────── = ────── ≈ 3183 A/m
      2π r     2π·0.1            π
```

**공심**

```
B = μ₀H = 4π×10⁻⁷ · (10000 / π) = 4×10⁻³ T
```

```
φ = BS = 4×10⁻³ · 4×10⁻⁴ = 1.6×10⁻⁶ Wb
```

**철심** (μ = 2000μ₀)

```
B = 2000 μ₀ H = 8 T
```

```
φ = BS = 3.2×10⁻³ Wb
```

핵심: **H는 같고 B, φ만 철심에서 커진다.**

## 문제 B9. (계산) 유한장 직선 (비오–사바르)

길이 L인 직선 도선 중심에서 수직거리 a인 점의 H를

```
       I
H = ────── (sinφ₁ + sinφ₂)
      4π a
```

로 구하려 한다. 도선 양 끝에서 그 점을 볼 때 φ₁ = φ₂ = φ라면 H는?
특별히 L → ∞이면?

### 해설

대칭이므로

```
       I                    I sinφ
H = ────── · 2 sinφ = ────────
      4π a                   2π a
```

기하:

```
             L/2
sinφ = ───────────────
       √[a² + (L/2)²]
```

무한장: φ → 90° , sinφ → 1

```
       I
H = ──────
      2π a
```

암페어 결과와 일치.

## 문제 B10. (계산) 전자력

B = 0.5 T인 평등자계에 길이 ℓ = 0.2 m 도선이 자계와 30°를 이루고
I = 10 A가 흐른다. 도선이 받는 힘의 크기는?

### 해설

```
F = BIl sinθ = 0.5 · 10 · 0.2 · sin30° = 1 · 0.5 = 0.5 N
```

방향은 플레밍 왼손법칙(검지 B, 중지 I, 엄지 F).

## 문제 B11. (계산) 운동전하 · 원운동

B = 0.2 T에 수직으로 속력 v = 10⁶ m/s인 전자
(q = e = 1.6×10⁻¹⁹ C, 질량 mₑ = 9.1×10⁻³¹ kg)가 들어간다.

1. 자기력의 크기
2. 원운동 반지름

```
      m v
r = ─────
      q B
```

### 해설

1. θ = 90°이므로
   F = Bqv = 0.2 · 1.6×10⁻¹⁹ · 10⁶ = 3.2×10⁻¹⁴ N

2. 구심력 = 자기력

```
m v² / r = B q v   →   r = m v / (q B)
```

```
      9.1×10⁻³¹ · 10⁶           9.1×10⁻²⁵
r = ──────────────────── = ──────────── ≈ 2.84×10⁻⁵ m
     1.6×10⁻¹⁹ · 0.2            3.2×10⁻²⁰
```

전자는 −전하라 힘 방향이 +전하와 반대임에 주의.

## 문제 B12. (계산) 평행도선 힘

두 무한장 평행도선이 d = 2 cm 떨어져 I₁ = I₂ = 30 A를 **같은 방향**으로 흘린다.
길이 1 m당 힘의 크기와 흡인/반발 여부를 구하시오.

### 해설

```
F     μ₀ I₁ I₂
─ = ─────────
ℓ       2π d
```

```
      4π×10⁻⁷ · 30 · 30
= ──────────────────── = 9×10⁻³ N/m
         2π · 0.02
```

같은 방향 → **흡인력** 9 mN/m.

## 문제 B13. (개념) 홀 효과

반도체에 +x 방향으로 전류, +z 방향으로 B를 걸었다.
홀 전압이 나타나는 대략적인 방향축은?

### 해설

I와 B에 **둘 다 수직**인 방향, 즉 y축 방향에 전하가 몰려 홀 전압이 생깁니다.
(F = q (v × B))

“환상 솔레노이드에 철심을 넣으면 자계의 세기 H가 커진다”는 설명이 틀렸다.
무엇이 커지는가? 한 문장으로 고치시오.

```
       N I

      2π r
```
