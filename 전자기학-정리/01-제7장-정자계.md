# 제7장 정자계 — 초보자용 정리

**정자계**란: 시간에 따라 변하지 않는 자계.  
원천은 **영구자석** 또는 **정상전류**입니다. 이 장에서는 주로 **자석**을 다룹니다.

---

## 7.1 자석 — 기본 용어

### 직관

막대자석을 철가루 위에 두면 N극·S극 근처가 가장 빽빽해집니다.  
그 “영향이 미치는 공간”이 자계이고, 그 방향을 선으로 그린 것이 자력선입니다.

### 용어

| 용어 | 의미 |
|---|---|
| 자기현상 | 자석끼리 끌어당기거나 밀치고, 철을 끌어당기는 현상 |
| 자극 | 작용이 강한 자석의 양 끝. N(+)극 / S(−)극 |
| 지구자석 | 나침반 N극이 가리키는 쪽(지리상 북쪽)은 **지구자석의 S극** |
| 자기력 | 동종극 반발, 이종극 흡인 |
| 자하 \(m\) | 자극의 세기. 단위 [Wb]. **항상 N·S가 같은 양으로 쌍으로 존재** |
| 자기유도 | 철편을 자계에 두면 일시적으로 자극이 생기는 현상 |
| 정자계 | 시간에 따라 변하지 않는 자계 |

### 전기와 가장 다른 점

- 전하는 \(+\)만 따로, \(-\)만 따로 존재할 수 있음.
- **자하는 홀로 떨어지지 않음.** 자석을 잘라도 항상 새 N·S가 생김.  
  → “고립자극(자기 홀극)은 없다.”

### 자석을 자르면?

막대자석을 반으로 자르면 N만 / S만 생기는 게 아니라,  
**작은 막대자석 두 개**(각각 N·S)가 됩니다.

## 7.2 쿨롱의 법칙 (자기)

### 점자극

두 극이 서로 영향을 거의 안 줄 만큼 **가늘고 긴 자석**을 가정한 가상 자극.

### 공식

\[
F = \frac{m_1 m_2}{4\pi\mu_0 r^{2}}\quad [\mathrm{N}]
\]

**기호형:** \(F = m_1 m_2 / (4\pi\mu_0 r^{2})\)

- 동종: 반발 / 이종: 흡인
- 진공의 투자율: \(\mu_0 = 4\pi\times 10^{-7}\ [\mathrm{H/m}]\)  
  (**μ₀ = 4π × 10⁻⁷ H/m**)

전기 쿨롱 \(F = Q_1 Q_2 / (4\pi\varepsilon_0 r^{2})\)에서  
\(Q \rightarrow m\),\ \(\varepsilon_0 \rightarrow \mu_0\) 로 바꾸면 됩니다.

---

## 7.3 자계의 세기 \(H\)

### 정의

자계 중 한 점에 **단위 자하 \(+1\ [\mathrm{Wb}]\)** 를 놓았을 때 받는 힘의 크기·방향.

단위: \([\mathrm{N/Wb}] = [\mathrm{A/m}]\)

### 공식

\[
H = \frac{m}{4\pi\mu_0 r^{2}}\quad [\mathrm{A/m}]
\]

\[
F = mH\quad [\mathrm{N}]
\]

**기호형:** \(H = m / (4\pi\mu_0 r^{2})\),\quad \(F = mH\)

전기의 \(E = Q/(4\pi\varepsilon_0 r^{2})\),\ \(F = QE\) 와 대응합니다.

---

## 7.4 자위와 자위차

### 비유

전기에서 “전위 = 단위 전하를 무한대에서 가져오는 데 드는 일”이듯,  
**자위 \(U\) = 단위 자하를 무한대에서 그 점까지 가져오는 데 드는 일**입니다.

### 공식

\[
U = -\int_{\infty}^{P} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell}\quad [\mathrm{A}]
\]

점자극:

\[
U = \frac{m}{4\pi\mu_0 r}\quad [\mathrm{A}]
\]

자위차:

\[
U_{AB} = -\int_{B}^{A} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = U_A - U_B
\]

**기호형:**

- \(U = -\displaystyle\int_{\infty}^{P} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell}\)
- \(U = m / (4\pi\mu_0 r)\)
- \(U_{AB} = U_A - U_B\)

전기: \(V = -\displaystyle\int \mathbf{E}\cdot\mathrm{d}\boldsymbol{\ell}\),\quad \(V = Q/(4\pi\varepsilon_0 r)\)

---

## 7.5 자기력선 (자력선)

### 정의

단위 자하 \(+1\ [\mathrm{Wb}]\)가 자기력을 따라 움직일 때 그리는 **가상선**.

### 성질 (암기용 5가지)

1. 바깥에서는 **N극에서 나와 S극으로 들어감** (자석 안에서는 S → N으로 이어져 폐회로)
2. **서로 교차하지 않음**
3. 선이 빽빽하면 자계가 셈 / 성기면 약함
4. 한 점에서 자계 방향 = 그 점에서의 **접선 방향**
5. 나침반 N극은 자력선 방향을 가리킴

### 자기력선수 \(N\)

균일·평면:

\[
N = \mathbf{H}\cdot\mathbf{S} = HS\cos\theta
\]

\(\theta = 0^{\circ}\) (면에 수직)이면 \(N = HS\)

불균일·곡면:

\[
N = \int_{S} \mathbf{H}\cdot\mathrm{d}\mathbf{S}
\]

매질과의 관계:

\[
N = \frac{m}{\mu_0}\quad\text{(자기)},\qquad
N = \frac{Q}{\varepsilon_0}\quad\text{(전기)}
\]

**기호형:** \(N = HS\cos\theta\),\quad \(N = \int_S \mathbf{H}\cdot\mathrm{d}\mathbf{S}\),\quad \(N = m/\mu_0\)

## 7.6 자속과 자속밀도

### 핵심 구분

| | 력선 수 \(N\) | 선속(전속/자속) |
|---|---|---|
| 의미 | 시각화용 선의 개수 | “원천의 총량” |
| 매질 | \(\varepsilon_0,\ \mu_0\)에 따라 변함 | **매질과 무관하게 일정** |
| 전기 | \(N = Q/\varepsilon_0\) | \(\psi = Q\) [C] |
| 자기 | \(N = m/\mu_0\) | \(\phi = m\) [Wb] |

자하 \(1\ [\mathrm{Wb}]\) → 자속 1개, 자하 \(m\) → 자속 \(m\)개: \(\phi = m\ [\mathrm{Wb}]\)

### 자속 \(\phi\)와 자속밀도 \(B\)

균일:

\[
\phi = \mathbf{B}\cdot\mathbf{S} = BS\cos\theta\quad [\mathrm{Wb}]
\]

불균일:

\[
\phi = \int_{S} \mathbf{B}\cdot\mathrm{d}\mathbf{S}\quad [\mathrm{Wb}]
\]

자속밀도:

\[
B = \frac{\phi}{S}\quad [\mathrm{Wb/m^{2}}]=[\mathrm{T}]
\]

\(B\)와 \(H\)의 관계 (진공):

\[
B = \mu_0 H
\]

**기호형:** \(\phi = BS\cos\theta\),\quad \(B = \phi/S\),\quad \(B = \mu_0 H\)

전기의 \(D = \varepsilon_0 E\)와 대응.

### 자속에 대한 가우스 정리 (매우 중요)

\[
\oint_{S} \mathbf{B}\cdot\mathrm{d}\mathbf{S} = 0
\]

미분형:

\[
\nabla\cdot\mathbf{B} = 0
\]

**기호형:** ∮_S **B** · d**S** = 0 ,\quad ∇ · **B** = 0

의미:

- 자속의 **연속성**
- **고립자극 없음**

전기 가우스와 비교:

\[
\oint_{S} \mathbf{D}\cdot\mathrm{d}\mathbf{S} = Q_{\mathrm{encl}},\qquad
\nabla\cdot\mathbf{D} = \rho_v
\]

**기호형:** ∮_S **D** · d**S** = Q ,\quad ∇ · **D** = ρᵥ

전기는 안에 전하가 있으면 알짜 전속이 있지만,  
자기는 안에 N만/S만 넣을 수 없으므로 알짜 자속이 항상 0입니다.

## 7.10 정전계와 정자계의 유사성 (대응표)

| 항목 | 정전계 | 정자계 |
|---|---|---|
| 원천 | \(Q\) [C] | \(m\) [Wb] |
| 매질상수 | \(\varepsilon_0 = 8.854\times 10^{-12}\ [\mathrm{F/m}]\) | \(\mu_0 = 4\pi\times 10^{-7}\ [\mathrm{H/m}]\) |
| 쿨롱 힘 | \(F = \dfrac{Q_1 Q_2}{4\pi\varepsilon_0 r^{2}}\) | \(F = \dfrac{m_1 m_2}{4\pi\mu_0 r^{2}}\) |
| 장의 세기 | \(E = \dfrac{Q}{4\pi\varepsilon_0 r^{2}}\) | \(H = \dfrac{m}{4\pi\mu_0 r^{2}}\) |
| 힘 | \(F = QE\) | \(F = mH\) |
| 전위 / 자위 | \(V = \dfrac{Q}{4\pi\varepsilon_0 r}\) | \(U = \dfrac{m}{4\pi\mu_0 r}\) |
| 경도 | \(\mathbf{E} = -\nabla V\) | \(\mathbf{H} = -\nabla U\) |
| 선속밀도 | \(D = \varepsilon_0 E\) | \(B = \mu_0 H\) |

> 예전에 `grad`로 쓰던 것은 수학 기호 **∇ (나블라)** 입니다.  
> \(\mathbf{E} = -\nabla V\),\quad \(\mathbf{H} = -\nabla U\)

**팁:** 자석에 의한 정자계는 정전계 공식을 그대로 “번역”하면 됩니다.  
전류에 의한 자계(8장)는 이 대응만으로는 부족합니다.
