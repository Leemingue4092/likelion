# 제7장 정자계 — 초보자용 정리

**정자계**란: 시간에 따라 변하지 않는 자계.  
원천은 **영구자석** 또는 **정상전류**입니다. 이 장에서는 주로 **자석**을 다룹니다.

---

## 7.1 자석 — 기본 용어

### 직관

막대자석을 철가루 위에 두면 N극·S극 근처가 가장 빽빽해집니다.  
그 “영향이 미치는 공간”이 자계이고, 그 방향을 선으로 그린 것이 자력선입니다.

### 용어

| 용어 | 의미 |
|---|---|
| 자기현상 | 자석끼리 끌어당기거나 밀치고, 철을 끌어당기는 현상 |
| 자극 | 작용이 강한 자석의 양 끝. N(+)극 / S(−)극 |
| 지구자석 | 나침반 N극이 가리키는 쪽(지리상 북쪽)은 **지구자석의 S극** |
| 자기력 | 동종극 반발, 이종극 흡인 |
| 자하 m | 자극의 세기. 단위 [Wb]. **항상 N·S가 같은 양으로 쌍으로 존재** |
| 자기유도 | 철편을 자계에 두면 일시적으로 자극이 생기는 현상 |
| 정자계 | 시간에 따라 변하지 않는 자계 |

### 전기와 가장 다른 점

- 전하는 +만 따로, −만 따로 존재할 수 있음.
- **자하는 홀로 떨어지지 않음.** 자석을 잘라도 항상 새 N·S가 생김.  
  → “고립자극(자기 홀극)은 없다.”

### 자석을 자르면?

막대자석을 반으로 자르면 N만 / S만 생기는 게 아니라,  
**작은 막대자석 두 개**(각각 N·S)가 됩니다.

---

## 7.2 쿨롱의 법칙 (자기)

### 점자극

두 극이 서로 영향을 거의 안 줄 만큼 **가늘고 긴 자석**을 가정한 가상 자극.

### 공식

> F = m₁m₂ / (4πμ₀r²) [N]

- 동종: 반발 / 이종: 흡인
- 진공의 투자율: **μ₀ = 4π × 10⁻⁷ H/m**

전기 쿨롱 F = Q₁Q₂ / (4πε₀r²) 에서  
Q → m , ε₀ → μ₀ 로 바꾸면 됩니다.

---

## 7.3 자계의 세기 H

### 정의

자계 중 한 점에 **단위 자하 +1 Wb** 를 놓았을 때 받는 힘의 크기·방향.

단위: [N/Wb] = [A/m]

### 공식

> H = m / (4πμ₀r²) [A/m]
>
> F = mH [N]

전기의 E = Q / (4πε₀r²) , F = QE 와 대응합니다.

---

## 7.4 자위와 자위차

### 비유

전기에서 “전위 = 단위 전하를 무한대에서 가져오는 데 드는 일”이듯,  
**자위 U = 단위 자하를 무한대에서 그 점까지 가져오는 데 드는 일**입니다.

### 공식

> U = −∫_∞^P H · dℓ [A]
>
> (점자극) U = m / (4πμ₀r) [A]
>
> U_AB = −∫_B^A H · dℓ = U_A − U_B

전기: V = −∫ E · dℓ , V = Q / (4πε₀r)

---

## 7.5 자기력선 (자력선)

### 정의

단위 자하 +1 Wb가 자기력을 따라 움직일 때 그리는 **가상선**.

### 성질 (암기용 5가지)

1. 바깥에서는 **N극에서 나와 S극으로 들어감** (자석 안에서는 S → N으로 이어져 폐회로)
2. **서로 교차하지 않음**
3. 선이 빽빽하면 자계가 셈 / 성기면 약함
4. 한 점에서 자계 방향 = 그 점에서의 **접선 방향**
5. 나침반 N극은 자력선 방향을 가리킴

### 자기력선수 N

균일·평면:

> N = H · S = HS cosθ

θ = 0° (면에 수직)이면 N = HS

불균일·곡면:

> N = ∫_S H · dS

매질과의 관계:

> (자기) N = m / μ₀
>
> (전기) N = Q / ε₀

---

## 7.6 자속과 자속밀도

### 핵심 구분

| | 력선 수 N | 선속(전속/자속) |
|---|---|---|
| 의미 | 시각화용 선의 개수 | “원천의 총량” |
| 매질 | ε₀, μ₀에 따라 변함 | **매질과 무관하게 일정** |
| 전기 | N = Q / ε₀ | ψ = Q [C] |
| 자기 | N = m / μ₀ | φ = m [Wb] |

자하 1 Wb → 자속 1개, 자하 m → 자속 m개: **φ = m [Wb]**

### 자속 φ와 자속밀도 B

균일:

> φ = B · S = BS cosθ [Wb]

불균일:

> φ = ∫_S B · dS [Wb]

자속밀도:

> B = φ / S [Wb/m²] = [T]

B와 H의 관계 (진공):

> B = μ₀H

전기의 D = ε₀E 와 대응.

### 자속에 대한 가우스 정리 (매우 중요)

> ∮_S B · dS = 0
>
> ∇ · B = 0

의미:

- 자속의 **연속성**
- **고립자극 없음**

전기 가우스와 비교:

> ∮_S D · dS = Q
>
> ∇ · D = ρᵥ

전기는 안에 전하가 있으면 알짜 전속이 있지만,  
자기는 안에 N만/S만 넣을 수 없으므로 알짜 자속이 항상 0입니다.

## 7.10 정전계와 정자계의 유사성 (대응표)

| 항목 | 정전계 | 정자계 |
|---|---|---|
| 원천 | Q [C] | m [Wb] |
| 매질상수 | ε₀ = 8.854 × 10⁻¹² F/m | μ₀ = 4π × 10⁻⁷ H/m |
| 쿨롱 힘 | F = Q₁Q₂ / (4πε₀r²) | F = m₁m₂ / (4πμ₀r²) |
| 장의 세기 | E = Q / (4πε₀r²) | H = m / (4πμ₀r²) |
| 힘 | F = QE | F = mH |
| 전위 / 자위 | V = Q / (4πε₀r) | U = m / (4πμ₀r) |
| 경도 | E = −∇V | H = −∇U |
| 선속밀도 | D = ε₀E | B = μ₀H |

> 예전에 grad로 쓰던 것은 수학 기호 **∇ (나블라)** 입니다.  
> E = −∇V , H = −∇U

**팁:** 자석에 의한 정자계는 정전계 공식을 그대로 “번역”하면 됩니다.  
전류에 의한 자계(8장)는 이 대응만으로는 부족합니다.
