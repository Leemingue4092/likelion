# 00. 한눈에 보기

## 1. 전기와 자기를 같이 보면 쉽다

정전계(전하)를 이미 배웠다면, **자석에 의한 정자계**는 거의 같은 틀로 대응됩니다.

| 개념 | 정전계 | 정자계(자석) |
|---|---|---|
| 원천 | 전하 Q [C] | 자극의 세기 m [Wb] |
| 매질 상수 | 유전율 ε₀ | 투자율 μ₀ |
| 힘과 장의 관계 | F = QE | F = mH |
| 선속밀도 | D = ε₀E | B = μ₀H |
| 선속 | ψ = Q | φ = m |

### 공식 (분수선 over 형태)

**쿨롱 (전기)**
```
        Q₁ Q₂
F = ────────────
       4π ε₀ r²
```

**쿨롱 (자기)**
```
        m₁ m₂
F = ────────────
       4π μ₀ r²
```

**전계 / 자계**
```
       Q                  m
E = ────────────    H = ────────────
     4π ε₀ r²            4π μ₀ r²
```

**전위 / 자위**
```
       Q                  m
V = ──────────      U = ──────────
     4π ε₀ r             4π μ₀ r
```

**선속밀도**
```
D = ε₀ E          B = μ₀ H
```

> **주의:** 8장에서 다루는 **전류에 의한 자계**는 “전하 ↔ 자극”처럼 1:1로 바로 대응되지 않습니다.
> 그때는 암페어 법칙·비오–사바르를 씁니다.

## 2. H와 B를 헷갈리지 말자

초보자가 가장 많이 섞는 부분입니다.

- **H (자계의 세기)**
  - “전류가 얼마나 자계를 만들었는가”에 가까운 양
  - 단위: [A/m]  (= A·m⁻¹)
  - 암페어 법칙: ∮ H · dℓ = I
  - **매질(철심/공심)과 무관한 경우가 많음** (같은 전류·같은 기하라면 H 동일)

- **B (자속밀도)**
  - “실제로 자속이 얼마나 빽빽한가”
  - 단위: [Wb/m²] = [T]
  - B = μH (진공이면 B = μ₀H)
  - **매질에 따라 달라짐** (철심이면 μ가 커서 B가 커짐)

비유: H는 “수도꼭지를 튼 힘”, B는 “파이프 안에 실제로 흐르는 물의 밀도”.
같은 힘으로 틀어도 파이프(매질)가 다르면 유량이 달라집니다.

## 3. 두 장의 흐름도

```text
[7장 정자계]
자석(N, S) → 쿨롱 법칙 → H → 자위 → 자력선
                              ↓
                         B = μ₀H → 자속 φ
                              ↓
                    가우스: ∮ B · dS = 0  (고립자극 없음)

[8장 전류에 의한 자계]
전류 I → 오른나사 법칙(방향)
       → 암페어 법칙(대칭 좋은 경우 H 계산)
       → 비오–사바르(대칭 나쁜 경우)
       → 전자력 F = Iℓ × B , 로렌츠힘 F = q(E + v × B)
```

## 5. 수업 필기 Q&A (헷갈린 부분)

### Q1. 왕복전류에서 “사이는 더해지고 바깥은 0”이 왜?

평행한 두 도선에 전류가 **반대 방향**으로 흐를 때(왕복):

1. 오른손 법칙으로 각 도선의 H 방향을 그린다.
2. **두 도선 사이**: 두 H가 같은 방향을 가리킴 → **합성 H가 커짐**.
3. **바깥쪽**: 두 H가 반대 → I가 같으면 **상쇄되어 H ≈ 0**.

같은 방향 전류면 반대로: 사이는 상쇄, 바깥은 보강 → 서로 **흡인**하는 쪽과 연결됩니다.

### Q2. 원주도체 외부 H 그래프가 “이차함수”인가?

아닙니다. 외부는

```
       I
H = ──────  ∝  1/r
      2π r
```

이라서 **반비례(쌍곡선 모양)** 입니다. r²에 비례하는 이차함수가 아닙니다.
내부(균일전류)만 H ∝ r 로 **직선**입니다.
