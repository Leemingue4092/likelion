# 00. 한눈에 보기

## 1. 전기와 자기를 같이 보면 쉽다

정전계(전하)를 이미 배웠다면, **자석에 의한 정자계**는 거의 같은 틀로 대응됩니다.

| 개념 | 정전계 | 정자계(자석) |
|---|---|---|
| 원천 | 전하 \(Q\) [C] | 자극의 세기 \(m\) [Wb] |
| 매질 상수 | 유전율 \(\varepsilon_0\) | 투자율 \(\mu_0\) |
| 힘 (쿨롱) | \(F=\dfrac{Q_1Q_2}{4\pi\varepsilon_0 r^2}\) | \(F=\dfrac{m_1m_2}{4\pi\mu_0 r^2}\) |
| 장의 세기 | \(E=\dfrac{Q}{4\pi\varepsilon_0 r^2}\) | \(H=\dfrac{m}{4\pi\mu_0 r^2}\) |
| 힘과 장의 관계 | \(F=QE\) | \(F=mH\) |
| 전위/자위 | \(V=\dfrac{Q}{4\pi\varepsilon_0 r}\) | \(U=\dfrac{m}{4\pi\mu_0 r}\) |
| 선속밀도 | \(D=\varepsilon_0 E\) | \(B=\mu_0 H\) |
| 선속 | \(\psi=Q\) | \(\phi=m\) |

> **주의:** 8장에서 다루는 **전류에 의한 자계**는 “전하 ↔ 자극”처럼 1:1로 바로 대응되지 않습니다.  
> 그때는 암페어 법칙·비오-사바르를 씁니다.

---

## 2. \(H\)와 \(B\)를 헷갈리지 말자

초보자가 가장 많이 섞는 부분입니다.

- **\(H\) (자계의 세기)**  
  - “전류가 얼마나 자계를 만들었는가”에 가까운 양  
  - 단위: \([AT/m]\) (= \(A/m\))  
  - 암페어 법칙: \(\oint H\cdot dl = I\)  
  - **매질(철심/공심)과 무관한 경우가 많음** (같은 전류·같은 기하라면 \(H\) 동일)

- **\(B\) (자속밀도)**  
  - “실제로 자속이 얼마나 빽빽한가”  
  - 단위: \([Wb/m^2]=[T]\)  
  - \(B=\mu H\) (진공이면 \(B=\mu_0 H\))  
  - **매질에 따라 달라짐** (철심이면 \(\mu\)가 커서 \(B\)가 커짐)

비유: \(H\)는 “수도꼭지를 튼 힘”, \(B\)는 “파이프 안에 실제로 흐르는 물의 밀도”.  
같은 힘으로 틀어도 파이프(매질)가 다르면 유량이 달라집니다.

## 3. 두 장의 흐름도

```text
[7장 정자계]
자석(N,S) → 쿨롱 법칙 → H → 자위 → 자력선
                              ↓
                         B = μH → 자속 φ
                              ↓
                    가우스: ∮ B·dS = 0  (고립자극 없음)

[8장 전류에 의한 자계]
전류 I → 오른나사 법칙(방향)
       → 암페어 법칙(대칭 좋은 경우 H 계산)
       → 비오-사바르(대칭 나쁜 경우)
       → 전자력 F = I × B , 로렌츠힘 F = q(E + v×B)
```

## 4. 반드시 외울 공식 TOP 10

1. \(\mu_0 = 4\pi\times 10^{-7}\,\mathrm{H/m}\)
2. \(F=\dfrac{m_1m_2}{4\pi\mu_0 r^2}\)
3. \(H=\dfrac{m}{4\pi\mu_0 r^2},\quad F=mH\)
4. \(B=\mu_0 H\) (진공), \(\phi=BS\) (균일·수직)
5. \(\oint_S B\cdot dS = 0\)
6. \(\oint_c H\cdot dl = I\) (또는 \(NI\))
7. 무한장 직선: \(H=\dfrac{I}{2\pi r}\)
8. 무한장 솔레노이드 내부: \(H=nI=\dfrac{NI}{l}\), 외부 \(H=0\)
9. 환상 솔레노이드: \(H=\dfrac{NI}{2\pi r}\)
10. 전자력: \(F=BIl\sin\theta\), 운동전하: \(F=Bqv\sin\theta\)

## 5. 수업 필기 Q&A (헷갈린 부분)

### Q1. 왕복전류에서 “사이는 더해지고 바깥은 0”이 왜?

평행한 두 도선에 전류가 **반대 방향**으로 흐를 때(왕복):

1. 오른손 법칙으로 각 도선의 \(H\) 방향을 그린다.
2. **두 도선 사이**: 두 \(H\)가 같은 방향을 가리킴 → **합성 \(H\)가 커짐**.
3. **바깥쪽**: 두 \(H\)가 반대 → \(I\)가 같으면 **상쇄되어 \(H\approx 0\)**.

같은 방향 전류면 반대로: 사이는 상쇄, 바깥은 보강 → 서로 **흡인**하는 쪽과 연결됩니다.

### Q2. 원주도체 외부 \(H\) 그래프가 “이차함수”인가?

아닙니다. 외부는

\[
H=\frac{I}{2\pi r}\propto \frac{1}{r}
\]

이라서 **반비례(쌍곡선 모양)** 입니다. \(r^2\)에 비례하는 이차함수가 아닙니다.  
내부(균일전류)만 \(H\propto r\)로 **직선**입니다.
