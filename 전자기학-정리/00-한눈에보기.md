# 00. 한눈에 보기

## 1. 전기와 자기를 같이 보면 쉽다

정전계(전하)를 이미 배웠다면, **자석에 의한 정자계**는 거의 같은 틀로 대응됩니다.

| 개념 | 정전계 | 정자계(자석) |
|---|---|---|
| 원천 | 전하 \(Q\) [C] | 자극의 세기 \(m\) [Wb] |
| 매질 상수 | 유전율 \(\varepsilon_0\) | 투자율 \(\mu_0\) |
| 힘 (쿨롱) | \(F = \dfrac{Q_1 Q_2}{4\pi\varepsilon_0 r^{2}}\) | \(F = \dfrac{m_1 m_2}{4\pi\mu_0 r^{2}}\) |
| 장의 세기 | \(E = \dfrac{Q}{4\pi\varepsilon_0 r^{2}}\) | \(H = \dfrac{m}{4\pi\mu_0 r^{2}}\) |
| 힘과 장의 관계 | \(F = QE\) | \(F = mH\) |
| 전위 / 자위 | \(V = \dfrac{Q}{4\pi\varepsilon_0 r}\) | \(U = \dfrac{m}{4\pi\mu_0 r}\) |
| 선속밀도 | \(D = \varepsilon_0 E\) | \(B = \mu_0 H\) |
| 선속 | \(\psi = Q\) | \(\phi = m\) |

**기호로 다시 쓰기 (렌더 없이도 읽기):**

- 쿨롱(전기): \(F = Q_1 Q_2 / (4\pi\varepsilon_0 r^{2})\)
- 쿨롱(자기): \(F = m_1 m_2 / (4\pi\mu_0 r^{2})\)
- 전계 / 자계: \(E = Q/(4\pi\varepsilon_0 r^{2})\),\quad \(H = m/(4\pi\mu_0 r^{2})\)
- 관계: \(D = \varepsilon_0 E\),\quad \(B = \mu_0 H\)

> **주의:** 8장의 **전류에 의한 자계**는 “전하 ↔ 자극”처럼 1:1로 바로 대응되지 않습니다.  
> 그때는 암페어 법칙·비오–사바르를 씁니다.

## 2. \(H\)와 \(B\)를 헷갈리지 말자

- **\(H\) (자계의 세기)**  
  - 단위: \([\mathrm{A\cdot m^{-1}}]\)  
  - 암페어 법칙: \(\displaystyle\oint H\cdot\mathrm{d}\boldsymbol{\ell} = I\)  
  - **매질과 무관한 경우가 많음**

- **\(B\) (자속밀도)**  
  - 단위: \([\mathrm{Wb\cdot m^{-2}}]=[\mathrm{T}]\)  
  - \(B = \mu H\) (진공: \(B = \mu_0 H\))  
  - **매질에 따라 달라짐**

비유: \(H\)는 “수도꼭지를 튼 힘”, \(B\)는 “파이프 안 물의 밀도”.

## 3. 두 장의 흐름도

```text
[7장 정자계]
자석(N, S) → 쿨롱 법칙 → H → 자위 → 자력선
                              ↓
                         B = μ₀H → 자속 φ
                              ↓
                    가우스: ∮ B · dS = 0  (고립자극 없음)

[8장 전류에 의한 자계]
전류 I → 오른나사 법칙(방향)
       → 암페어 법칙(대칭 좋은 경우 H 계산)
       → 비오–사바르(대칭 나쁜 경우)
       → 전자력 F = Iℓ × B , 로렌츠힘 F = q(E + v × B)
```

## 4. 반드시 외울 공식 TOP 10

1. \(\mu_0 = 4\pi\times 10^{-7}\ \mathrm{H/m}\)
2. \(F = \dfrac{m_1 m_2}{4\pi\mu_0 r^{2}}\)
3. \(H = \dfrac{m}{4\pi\mu_0 r^{2}},\quad F = mH\)
4. \(B = \mu_0 H\) (진공),\quad \(\phi = BS\) (균일·수직)
5. \(\displaystyle\oint_{S} \mathbf{B}\cdot\mathrm{d}\mathbf{S} = 0\)
6. \(\displaystyle\oint_{c} \mathbf{H}\cdot\mathrm{d}\boldsymbol{\ell} = I\) (또는 \(NI\))
7. 무한장 직선: \(H = \dfrac{I}{2\pi r}\)
8. 무한장 솔레노이드 내부: \(H = nI = \dfrac{NI}{l}\),\ 외부 \(H = 0\)
9. 환상 솔레노이드: \(H = \dfrac{NI}{2\pi r}\)
10. 전자력: \(F = BIl\sin\theta\),\ 운동전하: \(F = Bqv\sin\theta\)

**유니코드로 보면:**

1. μ₀ = 4π × 10⁻⁷ H/m  
2. F = m₁m₂ / (4πμ₀ r²)  
3. H = m / (4πμ₀ r²),\quad F = mH  
4. B = μ₀H,\quad φ = BS  
5. ∮_S **B** · d**S** = 0  
6. ∮_c **H** · d**ℓ** = I  
7. H = I / (2πr)  
8. H = nI = NI / ℓ\ (내부),\quad H = 0\ (외부)  
9. H = NI / (2πr)  
10. F = BIl sinθ,\quad F = Bqv sinθ

## 5. 수업 필기 Q&A (헷갈린 부분)

### Q1. 왕복전류에서 “사이는 더해지고 바깥은 0”이 왜?

평행한 두 도선에 전류가 **반대 방향**으로 흐를 때(왕복):

1. 오른손 법칙으로 각 도선의 \(H\) 방향을 그린다.
2. **두 도선 사이**: 두 \(H\)가 같은 방향 → **합성 \(H\)가 커짐**.
3. **바깥쪽**: 두 \(H\)가 반대 → \(I\)가 같으면 **상쇄되어 \(H \approx 0\)**.

### Q2. 원주도체 외부 \(H\) 그래프가 “이차함수”인가?

아닙니다. 외부는

\[
H = \frac{I}{2\pi r} \propto \frac{1}{r}
\]

즉 **H ∝ 1/r** (반비례). 이차함수(∝ r²)가 아닙니다.  
내부(균일전류)만 **H ∝ r** 로 직선입니다.
