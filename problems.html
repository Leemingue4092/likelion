A. 제7장

A1. 자석을 잘랐을 때

막대자석을 가운데서 자르면?

  1. N만 / S만
  2. 각각 N·S를 가진 작은 자석 둘
  3. 자극 없는 철조각

정답 2. 자하는 홀로 존재할 수 없어, 잘라도 작은 자석 두 개가 됩니다.

A2. 가우스 정리

∮_S B · dS 의 값은?

  1. m에 비례하는 양수
  2. 항상 0
  3. 자석 길이에 비례

정답 2.

∇ · B = 0,  ∮ B · dS = 0

고립자극이 없으므로 알짜 자속은 항상 0.

A3. 쿨롱 자기력

m₁ = m₂ = 2×10⁻⁴ Wb, r = 0.1 m (동종). 힘의 크기는?

F = m₁ m₂4π μ₀ r²

계산하면 F ≈ 0.253 N (반발).

A5. B와 φ

H = 200 A/m, S = 0.05 m² (수직, 진공). B와 φ는?

B = μ₀H = 8π×10⁻⁵ ≈ 2.51×10⁻⁴ T
φ = BS = 4π×10⁻⁶ ≈ 1.26×10⁻⁵ Wb

B. 제8장

B1. 오른손 법칙

전류 ⊙일 때, 도선 오른쪽에서 H 방향은? (위/아래/왼쪽/오른쪽)

위쪽. 나오는 전류는 반시계 방향 자계.

B3. 알짜 전류

I₁=3A(⊙), I₂=5A(⊗), I₃=2A(⊙). ∮ H · dℓ = ?

I_encl = 3 − 5 + 2 = 0 → ∮ H · dℓ = 0

B4. 무한장 직선

I = 10 A, r = 0.05 m. H와 B(진공)는?

H = I2π r = 100/π ≈ 31.8 A/m

B = μ₀H = 4×10⁻⁵ T

B5. 원주도체

a = 0.02 m, I = 20 A 균일. r = 1, 2, 4 cm에서 H는?

내부 r=1cm: H = rI/(2πa²) ≈ 79.6 A/m
표면 r=2cm: H = I/(2πa) ≈ 159 A/m
외부 r=4cm: H = I/(2πr) ≈ 79.6 A/m

내부 ∝ r, 외부 ∝ 1/r

B7. 솔레노이드

ℓ=0.5 m, N=1000, I=2 A. 내부·외부 H와 내부 B는?

H = N Iℓ = 4000 A/m

외부 H = 0, B = μ₀H ≈ 5.03×10⁻³ T

B8. 환상 솔레노이드

r=0.1 m, N=500, I=4 A, S=4×10⁻⁴ m². 공심/철심(μ=2000μ₀)에서 H,B,φ?

H = N I2π r ≈ 3183 A/m (공심·철심 동일)

공심: B=4×10⁻³ T, φ=1.6×10⁻⁶ Wb
철심: B=8 T, φ=3.2×10⁻³ Wb

B10. 전자력

B=0.5 T, ℓ=0.2 m, θ=30°, I=10 A. F는?

F = BIl sinθ = 0.5·10·0.2·0.5 = 0.5 N

B14. H vs B 함정

“철심을 넣으면 H가 커진다”를 고치시오.

철심을 넣어도

H = N I2π r

는 그대로이고, B와 φ가 커진다.
