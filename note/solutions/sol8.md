# 8장 1차 RL/RC 완전응답 — 연습·기출 풀이

읽은 범위: 연습 p025–p030 (8.1–8.17). p031은 연습이 끝난 뒤의 컴퓨터 프로젝트라 맨 아래에 짧게만 적는다. 기출 p032–p038 (8.1–8.18).

공통 절차: 스위칭 전 직류 정상상태에서 L은 단락, C는 개방으로 초기값을 정한다. 스위칭 후 τ = L/R_eq 또는 RC, 최종값은 전원을 살린 채 L 단락·C 개방. x(t) = x(∞) + (x(0) − x(∞))e^{−t/τ}. 무전원 회로는 최종값 0. 스위치가 다시 움직이면 그 순간의 상태가 다음 초기값이다. 정현·계단이 아닌 시간함수 전원은 정상해(특수해) + 과도해를 더한다.

값은 그림을 잘라 다시 읽은 것이다. 스위치 방향이 문장으로 안 적힌 곳은 그림에서 읽은 방향을 적고 신뢰도를 낮춘다.

## 연습문제

### 연습 8.1

- **정답:** i_L(t) = 8(1 - e^{-250t}) A (t > 0). i_L(4 ms) ≈ 5.057 A, i_L(∞) = 8 A.

- 회로: 전류원 8u(t) A, 100 Ω, 0.4 H가 병렬. i_L은 인덕터 아래 방향.
- τ = L/R = 0.4/100 = 4 ms.
- 초기: t < 0이면 전원이 0이라 i_L(0) = 0.
- 최종: 인덕터가 100 Ω을 단락하므로 i_L(∞) = 8 A.
- i_L(t) = 8(1 − e^{−250t}) A (t > 0, t의 단위는 s).
- 요구 시각: i_L(0+) = 0, i_L(4 ms) = 8(1 − e^{−1}) ≈ 5.057 A, i_L(∞) = 8 A.
- 신뢰도: 높음.

### 연습 8.2

- **정답:** t = 3 ms에서 저항 ≈ 71.40 W, 인덕터 ≈ 79.76 W, 전류원 ≈ -151.16 W (공급 151.16 W). i_L(t) = 8(1 - e^{-250t}) A.

- 회로: 8u(t) A, 5 Ω, 20 mH 병렬. t = 3 ms에서 저항·인덕터·전원의 소비전력.
- τ = 0.02/5 = 4 ms.
- 초기 0, 최종 8 A. i_L(t) = 8(1 − e^{−250t}) A.
- t = 3 ms에서 e^{−0.75} ≈ 0.47237.
  - v = L di_L/dt = 40 e^{−250t} ≈ 18.895 V (위가 +).
  - i_L ≈ 4.221 A, i_R = v/5 ≈ 3.779 A. i_R + i_L = 8 A로 맞는다.
- 소비전력(흡수, 수동부호):
  - 저항 v·i_R ≈ 71.40 W
  - 인덕터 v·i_L ≈ 79.76 W
  - 전류원 −8v ≈ −151.16 W (151.16 W를 공급)
- 신뢰도: 높음.

### 연습 8.3

- **정답:** i(t) = 2 + (3/2)t A. i_R = 1 A, i_L1 = 1 + t A, i_L2 = t/2 A. 감쇠 시정수 없음.

- 회로: 1 V(+가 위)에 1 Ω, 1 H, 2 H가 병렬. i는 전원에서 오른쪽으로 나가는 전류. i_{L1}(0+) = 1 A, i_{L2}(0+) = 0.
- 세 소자의 전압이 1 V로 고정된다. 병렬 인덕터에는 직렬 저항이 없어 전류가 직선으로 증가한다.
- L_eq = 1 H ∥ 2 H = 2/3 H, di_L/dt = 1/(2/3) = 3/2.
- 미분방정식: di/dt = 3/2 (t > 0), i(0+) = i_R + i_{L1} + i_{L2} = 1 + 1 + 0 = 2 A.
- 해: i(t) = 2 + (3/2)t A.
- 따로 쓰면 i_R = 1 A, i_{L1} = 1 + t A, i_{L2} = t/2 A.
- τ: 감쇠 시정수가 없다(강제 램프). 최종값은 무한대.
- 신뢰도: 높음.

### 연습 8.4

- 신뢰도: 높음. 250 mF는 글자를 다시 읽어도 mF이다.

- 출력으로 전류가 나가지 않는다. 노드 KCL: i_1 + 2 i_1 = v_A → v_A = 3 i_1.
- 커패시터 왼쪽이 전원 쪽, 전압 연속. t < 0 휴지라 v_C(0) = 0, v_A(0+) = 1, i_1(0+) = 1/3.
- 3 i_1' + i_1 = d(e^{−t})/dt = −e^{−t}.
- i_1(t) = (1/2)e^{−t} − (1/6)e^{−t/3} A.
- v_o = v_A + 2 i_1 = 5 i_1 = (5/2)e^{−t} − (5/6)e^{−t/3} V.
- ④. 종속원 극성을 뒤집으면 v_o = i_1이 되어 선택지에 없다.
- 신뢰도: 높음.
