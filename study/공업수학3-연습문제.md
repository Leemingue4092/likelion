# 공업수학3 연습문제

과제와 같은 계산량으로 맞춰 두었다.
정답과 풀이는 아래 **정답** 구분선 다음에 있다. 풀기 전에는 그 아래로 내려가지 않는다.

## A. 유형만 고르기

방정식을 풀지 말고, 방법 이름만 적는다.
선형 동차, 선형 비동차, 베르누이, 변수분리, 완전미분, 동차형(`v=y/x`) 중에서 고른다.
두 방법이 되면 더 짧은 쪽을 고르고, 다른 쪽을 괄호로 적는다.

1. `y' + (3/x) y = 0`
2. `y' + (3/x) y = x^2`
3. `y' + y = e^(-x) y^2`
4. `(2xy + 3) dx + x^2 dy = 0`
5. `y' = (x^2 + y^2)/(x y)`
6. `y' = x (1 - y^2)`
7. `y' + 2y = 2 y^2`
8. `(y cos x + 2x) dx + sin x dy = 0`

## B. 적분

1. `∫_0^4 x √(x^2+9) dx`
2. `∫_0^1 dx/(x^2 + 3x + 2)`
3. `∫ x/(1 - x^4) dx`
4. `∫ (4x+2)/((x^2+1)(x^2+4)) dx`

## C. 미분방정식

1. `dy/dx = (x+2) y^2`
2. `dy/dx = 2x y (y-1)`, `y(0)=2`
3. `y' + 2x y = 0`, `y(0)=5`
4. `y' - y sin x = 0`, `y(0)=2`
5. `y' + 2y = 4x`
6. `y' - y = e^(2x)`, `y(0)=1`
7. `y' + y = sin x`
8. `y' + y = e^x y^2`
9. `y' + 2y = 2 y^2`
10. `(2xy + 3) dx + x^2 dy = 0`
11. `(y cos x + 2x) dx + sin x dy = 0`
12. `y' = 1 + y/x`  
    이건 과제에 없던 동차형이다. `v=y/x`로 푼다.

# 정답

## A. 유형

1. 선형 동차 (변수분리로도 된다)
2. 선형 비동차
3. 베르누이 (`n=2`)
4. 완전미분. `M_y = 2x = N_x`
5. 동차형 `v=y/x`. `f(tx,ty)=f(x,y)`
6. 변수분리
7. 베르누이 (`n=2`). 우변이 `y`만의 함수라 변수분리로도 된다
8. 완전미분. `M_y = cos x = N_x`

## B. 적분 풀이

### B1

`u = x^2+9`. `x: 0→4`이면 `u: 9→25`, `x dx = du/2`.

```text
(1/2) ∫_9^25 u^(1/2) du
= (1/3) [ u^(3/2) ]_9^25
= (1/3) (125 - 27)
= 98/3
```

`25^(3/2)=125`, `9^(3/2)=27`.

### B2

```text
x^2+3x+2 = (x+1)(x+2)
1/((x+1)(x+2)) = 1/(x+1) - 1/(x+2)
```

```text
[ ln(x+1) - ln(x+2) ]_0^1
= (ln 2 - ln 3) - (0 - ln 2)
= ln 4 - ln 3
= ln(4/3)
```

### B3

`u=x^2`이면 `du=2x dx`.

```text
(1/2) ∫ du/(1-u^2)
= (1/4) ln |(1+u)/(1-u)| + C
= (1/4) ln |(1+x^2)/(1-x^2)| + C
```

`1/(1-u^2) = (1/2) [ 1/(1-u) + 1/(1+u) ]`로 부분분수해도 같다.
절댓값 안에서는 `(1+x^2)/(1-x^2)`와 `(x^2+1)/(x^2-1)`이 부호만 다르다.

### B4

```text
(4x+2)/((x^2+1)(x^2+4))
= (2/3) (2x+1)/(x^2+1) - (2/3) (2x+1)/(x^2+4)
```

각 항을 `2x`와 상수로 나눈다.

```text
(2/3) ∫ 2x/(x^2+1) dx = (2/3) ln(x^2+1)
(2/3) ∫ 1/(x^2+1) dx = (2/3) arctan x
(2/3) ∫ 2x/(x^2+4) dx = (2/3) ln(x^2+4)
(2/3) ∫ 1/(x^2+4) dx = (2/3) · (1/2) arctan(x/2) = (1/3) arctan(x/2)
```

```text
(2/3) ln |(x^2+1)/(x^2+4)| + (2/3) arctan x - (1/3) arctan(x/2) + C
```

## C. 미분방정식 풀이

### C1. 변수분리

```text
dy/y^2 = (x+2) dx
-1/y = x^2/2 + 2x + C
y = -2 / (x^2 + 4x + K)
```

`y=0`도 해다. 일반해 식에는 `K→∞`처럼만 들어간다.

### C2. 변수분리, 초기조건

```text
dy/(y(y-1)) = 2x dx
1/(y(y-1)) = 1/(y-1) - 1/y
ln |(y-1)/y| = x^2 + C
```

`y(0)=2`이면 `ln(1/2)=C`.

```text
(y-1)/y = (1/2) e^(x^2)
1/y = 1 - (1/2) e^(x^2)
y = 2 / (2 - e^(x^2))
```

`x=0`에서 `y=2`. 분모가 0이 되는 `x = ±√(ln 2)` 근처에서는 이 해가 끊긴다.

### C3. 선형 동차

```text
dy/y = -2x dx
ln|y| = -x^2 + C
y = K e^(-x^2)
y(0)=5 → K=5
y = 5 e^(-x^2)
```

### C4. 선형 동차

```text
dy/y = sin x dx
ln|y| = -cos x + C
y = K e^(-cos x)
```

`y(0)=2`이면 `K e^(-1) = 2`, `K=2e`.

```text
y = 2 e^(1 - cos x)
```

### C5. 선형 비동차

`P=2`, `μ=e^(2x)`.

```text
d/dx (y e^(2x)) = 4x e^(2x)
∫ 4x e^(2x) dx = 2x e^(2x) - e^(2x)
y = 2x - 1 + C e^(-2x)
```

부분적분: `u=x`, `dv=4e^(2x)dx`, `v=2e^(2x)`.

### C6. 선형 비동차, 초기조건

`P=-1`, `μ=e^(-x)`.

```text
d/dx (y e^(-x)) = e^x
y e^(-x) = e^x + C
y = e^(2x) + C e^x
```

`y(0)=1`이면 `1+C=1`, `C=0`.

```text
y = e^(2x)
```

검산: `y'-y = 2e^(2x) - e^(2x) = e^(2x)`, `y(0)=1`.

### C7. 선형 비동차

`μ=e^x`. `I = ∫ e^x sin x dx`.

```text
I = e^x sin x - ∫ e^x cos x dx
  = e^x sin x - e^x cos x - ∫ e^x sin x dx
2I = e^x (sin x - cos x)
I = (1/2) e^x (sin x - cos x)
```

```text
y = (1/2)(sin x - cos x) + C e^(-x)
```

### C8. 베르누이

`n=2`, `u=y^(-1)`, `u'=-y^(-2) y'`.
`y^2`으로 나누면

```text
y^(-2) y' + y^(-1) = e^x
-u' + u = e^x
u' - u = -e^x
```

`μ=e^(-x)`.

```text
d/dx (u e^(-x)) = -1
u e^(-x) = -x + C
u = (C - x) e^x
y = e^(-x) / (C - x)
```

`y=0`도 원래 식을 만족한다.

### C9. 베르누이

`n=2`, `u=1/y`.

```text
y' + 2y = 2 y^2
y^(-2) y' + 2 y^(-1) = 2
-u' + 2u = 2
u' - 2u = -2
```

`μ=e^(-2x)`.

```text
d/dx (u e^(-2x)) = -2 e^(-2x)
u e^(-2x) = e^(-2x) + C
u = 1 + C e^(2x)
y = 1 / (1 + C e^(2x))
```

`y=0`도 해다. `C=0`이면 평형해 `y=1`.

### C10. 완전미분

`M=2xy+3`, `N=x^2`. `M_y=2x=N_x`.

```text
f = ∫ (2xy+3) dx = x^2 y + 3x + h(y)
f_y = x^2 + h' = x^2
h' = 0
x^2 y + 3x = C
y = (C - 3x) / x^2
```

### C11. 완전미분

`M = y cos x + 2x`, `N = sin x`. `M_y = cos x = N_x`.

```text
f = ∫ N dy = y sin x + g(x)
f_x = y cos x + g' = y cos x + 2x
g' = 2x,  g = x^2
y sin x + x^2 = C
```

### C12. 동차형

`y' = 1 + y/x`. `y=vx`, `y'=v + x v'`.

```text
v + x v' = 1 + v
x dv/dx = 1
v = ln|x| + C
y = x ln|x| + C x
```

## 손으로 확인할 때

- 초기조건 문제는 구한 `y`에 `x`를 넣어 주어진 `y`가 나오는지 본다.
- 완전미분은 `df`를 전개해 `M dx + N dy`가 되는지 본다.
- 정적분은 원시함수의 위끝·아래끝을 각각 계산한 뒤 뺀다. `ln` 두 개는 빼기 전에 `ln(몫)`으로 합친다.
- 베르누이는 `y=0`을 나누기 전에 따로 대입해 본다.
