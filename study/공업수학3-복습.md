## 1. 유형 판별

식의 모양만 보고 방법을 고른다. 이름 "동차"가 두 가지라서 여기서 갈라 둔다.

| 식의 모양 | 이름 | 첫 손 |
| --- | --- | --- |
| `dy/dx = f(x) g(y)` | 변수분리 | `dy/g(y) = f(x) dx` |
| `y' + P(x) y = 0` | 선형 **동차** | `y = C exp(-∫P dx)` |
| `y' + P(x) y = Q(x)` | 선형 **비동차** | 적분인자 `μ = exp(∫P dx)` |
| `y' + P(x) y = Q(x) y^n` (`n≠0,1`) | 베르누이 | `u = y^(1-n)` |
| `M dx + N dy = 0` 이고 `∂M/∂y = ∂N/∂x` | 완전미분 | `f`를 찾아 `f=C` |
| `y' = F(y/x)` 만으로 적힘 | **동차형** (`v=y/x`) | `y = v x` |

과제2에서 푼 동차/비동차는 위 표의 **선형** 동차·비동차다.
`v = y/x`로 푸는 동차형은 제출한 과제에는 없다. 이름만 같아서 시험 전에 구분해 둔다.

적분은 피적분함수 모양으로 고른다.

- 근호 안에 `x^2 + a^2` 있고 앞에 `x`가 있으면 치환 `u = x^2 + a^2`.
- 분모가 인수분해되는 유리식이면 부분분수.
- 분모에 `x^2 + a^2`가 남으면 `arctan(x/a)`.

## 2. 공식 카드

### 선형 1계

표준형으로 먼저 맞춘다.

```text
dy/dx + P(x) y = Q(x)
```

적분인자

```text
μ(x) = exp(∫ P(x) dx)
```

양변에 곱하면 왼쪽이 곱의 미분이 된다.

```text
d/dx (μ y) = μ Q
y = (1/μ) ( ∫ μ Q dx + C )
```

`Q = 0`이면 적분이 사라져서

```text
y = C exp(-∫ P dx)
```

초기조건이 있으면 일반해를 구한 뒤 그 점을 넣어 `C`를 정한다.

### 베르누이

```text
y' + P(x) y = Q(x) y^n    (n ≠ 0, 1)
u = y^(1-n)
```

`u`로 바꾸면 선형 비동차가 된다.

```text
u' + (1-n) P(x) u = (1-n) Q(x)
```

`(1-n)`을 `P`와 `Q` **양쪽**에 곱하는 것을 빠뜨리면 틀린다.
`y^n`으로 나눌 때 `y = 0`이 해인지 따로 확인한다. `n>1`이면 `y=0`이 보통 해다.

### 변수분리

```text
dy/dx = f(x) g(y)
∫ dy/g(y) = ∫ f(x) dx
```

`g(y)=0`을 만드는 상수해는 나누기 전에 한 번 본다.

### 완전미분

```text
M(x,y) dx + N(x,y) dy = 0
∂M/∂y = ∂N/∂x   이면 완전
```

1. `y`를 상수로 보고 `∫ M dx = f`의 뼈대를 만든다. 적분상수는 `h(y)`.
2. `∂f/∂y = N`으로 `h'(y)`를 구한다.
3. `f(x,y) = C`.

검산은 `df`를 다시 전개해서 `M dx + N dy`가 나오는지 보는 것이다.

### 동차형 `v = y/x` (과제에는 없었음)

`y' = F(y/x)`이면 `y = v x`, `y' = v + x v'`를 넣는다.
`v`와 `x`의 변수분리 방정식이 된다.

예: `y' = 1 + y/x`

```text
v + x v' = 1 + v
x v' = 1
v = ln|x| + C
y = x ln|x| + C x
```

### 적분

치환 `u = x^2 + a^2`이면 `du = 2x dx`.

```text
∫ x √(x^2+a^2) dx = (1/3) (x^2+a^2)^(3/2) + C
```

거듭제곱은 이렇게 읽는다.

```text
(a^2)^(3/2) = a^3
(2 a^2)^(3/2) = (2 a^2) · a √2 = 2√2 · a^3
```

`a^(3/2)`와 `a^3`은 다르다.

부분분수에서 분모에 서로 다른 일차인수가 있으면

```text
1/((x-a)(x-b)) = A/(x-a) + B/(x-b)
```

기약 이차인수 `x^2+a^2`에는 분자를 1차까지 둔다.

```text
(Bx + C)/(x^2 + a^2)
```

자주 쓰는 적분

```text
∫ dx/(x^2+a^2) = (1/a) arctan(x/a)
∫ (2x)/(x^2+a^2) dx = ln(x^2+a^2)
```

로그 차이는 진약분수로 합친다.

```text
A ln p - A ln q = A ln(p/q)
2 ln(3/2) = ln(9/4)
```

## 3. 과제 검산

아래 답은 식을 다시 풀고, 가능하면 원식에 대입해 확인한 결과다.

### 4주차. 적분 복습

**(1)** `∫_0^a x √(x^2+a^2) dx` (`a>0`)

최종 답은 맞다.

```text
(a^3 / 3) (2√2 - 1)
```

중간 지수만 고쳐 둔다.

```text
u = x^2+a^2,  x=0 → a^2,  x=a → 2a^2
(1/2) ∫_{a^2}^{2a^2} √u du
= (1/3) [ (2a^2)^(3/2) - (a^2)^(3/2) ]
= (1/3) (2√2 a^3 - a^3)
```

노트에는 `(2a^2)^(3/2)`를 `2^(3/2) a^(3/2)`처럼 적었다.
` (a^2)^(3/2) = a^3 `이라서 지수는 `a^3`이어야 한다. 마지막 줄의 `a^3`은 맞다.

**(2)** `∫_0^1 2/(2x^2+3x+1) dx`

맞다.

```text
2/((2x+1)(x+1)) = 4/(2x+1) - 2/(x+1)
[ 2 ln(2x+1) - 2 ln(x+1) ]_0^1
= 2 ln 3 - 2 ln 2
= 2 ln(3/2)
= ln(9/4)
```

`2 ln(3/2)`와 `ln(9/4)`는 같은 수다.

### 과제1. 부분분수

**(1)** `∫ dx/(1-x^4)`

맞다.

```text
1-x^4 = (1-x)(1+x)(1+x^2)
1/(1-x^4) = (1/4)/(1-x) + (1/4)/(1+x) + (1/2)/(1+x^2)

(1/4) ln |(1+x)/(1-x)| + (1/2) arctan x + C
```

`x=1`에서 `A(1+1)(1+1)=1`이므로 `A=1/4`. `x=-1`에서 `B=1/4`.
남은 식에서 `x^3` 계수가 `-C`라서 `C=0`, 상수항에서 `D=1/2`.

**(2)** `∫ (2x+1)/((x^2+1)(x^2+4)) dx`

맞다.

```text
(2x+1)/(3(x^2+1)) - (2x+1)/(3(x^2+4))

(1/3) ln |(x^2+1)/(x^2+4)| + (1/3) arctan x - (1/6) arctan(x/2) + C
```

`∫ dx/(x^2+4) = (1/2) arctan(x/2)`라서 앞의 `1/3`과 만나 `1/6`이 된다.

### 과제2. 1계 미분방정식

**(변수분리)** `dy/dx + (x+1) y^2 = 0`

맞다. 상수 쓰는 방식만 다르고 같은 해다.

```text
dy/y^2 = -(x+1) dx
1/y = x^2/2 + x + C
y = 2 / (x^2 + 2x + K)
```

**(변수분리, 초기조건)** `(1/x) dy/dx = y^2 - y`, `y(1)=2`

최종 답은 맞다.

```text
y = 2 / (2 - exp((x^2-1)/2))
```

확인: `x=1`이면 분모가 `2-1=1`이라 `y=2`.

풀이 골격은 이렇다.

```text
dy/(y(y-1)) = x dx
1/(y(y-1)) = 1/(y-1) - 1/y
ln |(y-1)/y| = x^2/2 + C
```

`(1,2)`를 넣으면 `C = ln(1/2) - 1/2`.
`(y-1)/y = (1/2) exp((x^2-1)/2)`를 `y`에 대해 풀면 위 식이 된다.

**(선형 비동차)** `y' + 2y = 2x`

맞다.

```text
μ = e^(2x)
y = x - 1/2 + C e^(-2x)
```

**(선형 동차, 초기조건)** `y' - y cos x = 0`, `y(0)=1`

맞다.

```text
y = e^(sin x)
```

**(선형 동차, 초기조건)** `y' + y/x^2 = 0`, `y(-1)=e^(-1)`

맞다.

```text
y = exp(1/x)
```

**(선형 비동차)** `y' + y = cos x`

맞다.

```text
∫ e^x cos x dx = (1/2) e^x (sin x + cos x)
y = (1/2)(sin x + cos x) + C e^(-x)
```

**(베르누이)** `y' + y = e^(-x) y^2`

맞다. `n=2`, `u=1/y`.

```text
u' - u = -e^(-x)
u = (1/2) e^(-x) + C e^x
y = 2 / (e^(-x) + 2 C e^x)
```

같은 해를 `y = 2 e^x / (1 + K e^(2x))`로 적어도 된다. 분자·분모에 `e^x`를 곱한 것이다.

**(완전미분)** `(2xy+y) dx + (x^2+x) dy = 0`으로 읽히면 답이 맞다.

```text
∂M/∂y = 2x+1 = ∂N/∂x
f = x^2 y + x y
y = C / (x(x+1))
```

검산:

```text
d[ x(x+1) y ] = (2x+1) y dx + x(x+1) dy
             = (2xy + y) dx + (x^2 + x) dy
```

노트에 `dy` 계수를 `x^2+2x`로 적어 두었다면 그 식은 완전이 아니다.
그때 `∂N/∂x = 2x+2`라서 `∂M/∂y = 2x+1`과 다르다.
원 문제의 `N`이 `x^2+x`인지 `x^2+2x`인지만 원문과 한 번 대조하면 된다.

## 4. 유형별로 다시 푸는 흐름

새 문제를 풀기 전에, 이미 맞은 문제에서 손 순서만 고정한다.

### 부분분수

1. 분모를 인수분해한다. `1-x^4=(1-x)(1+x)(1+x^2)`.
2. 일차인수에는 상수, 이차인수에는 `Cx+D`.
3. 대입하기 좋은 `x`로 `A,B`를 먼저 구한다.
4. 남은 계수를 비교해 `C,D`를 구한다.
5. `1/(x^2+a^2)`는 `arctan`, `2x/(x^2+a^2)`는 `ln`.

### 선형 비동차

1. `y' + P y = Q`로 맞춘다.
2. `μ = exp(∫P dx)`.
3. `∫ μ Q dx`를 부분적분으로 계산한다.
4. `μ`로 나눈다.

`y' + 2y = 2x`에서는 `μ=e^(2x)`, `∫ 2x e^(2x) dx = x e^(2x) - (1/2) e^(2x)`.

### 베르누이

1. `n`을 읽는다. 과제 문제는 `n=2`.
2. `u = y^(1-n)`. `n=2`이면 `u=y^(-1)`, `u' = -y^(-2) y'`.
3. 원식을 `y^n`으로 나누고 `u`만 남긴다.
4. 그 선형 방정식을 적분인자로 푼 뒤 `y=u^(1/(1-n))`.

### 완전미분

1. `M_y`와 `N_x`가 같은지 **먼저** 계산한다. 같다는 결론을 미리 적지 않는다.
2. 같으면 `∫ M dx` 후 `h(y)`.
3. `f=C`를 `y`에 대해 정리한다.
4. `df`로 검산한다.
